| 3. 핵심 규칙 | 26초 | 핵심 규칙<br>과거의 한 때보다 더 먼저 일어난 일 → 과거완료 had + 과거분사<br>기준이 되는 과거의 일 → 단순과거<br>예) I heard that Sam had moved to Busan. | 4. 풀이 순서 | 34초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** 우리말의 순서: 창문을 연 일(먼저) → 알게 된 일(나중, 기준) / 강조 `창문을 이미 열어 두었다`, `알게 되었다`<br>**2단계** 첫째 빈칸 = 기준인 알게 된 일 → 단순과거 found. had found·has found로 시작하는 보기 지움 / 강조 `Mina _____` / 지움 `② had found — had opened`, `③ has found — has opened`, `⑤ had found — opened`<br>**3단계** 둘째 빈칸 = 더 먼저 연 일 → had opened. opened만 쓴 ① 지움 → ④ / 강조 `someone _____ the window already.`, `④ found — had opened` / 지움 `① found — opened` | 첫째, 우리말을 보면 누군가 창문을 연 일이 먼저이고, Mina가 그것을 알게 된 일이 나중이에요. 둘째, 첫째 빈칸은 기준이 되는 나중 일, 알게 된 일이라 단순과거 found로 써요. 그래서 had found나 has found로 시작하는 2번, 3번, 5번을 지워요. 셋째, 둘째 빈칸은 그보다 더 먼저 연 일이라 had opened로 써요. 그래서 opened만 쓴 1번도 지우면, 4번 found와 had opened가 남아요. | 순서 → found → had opened |
| 5. 선택지 확인 | 26초 | ① found — opened  ✗  더 먼저 연 일은 opened가 아니라 had opened로 써요<br>② had found — had opened  ✗  기준인 알게 된 일은 had found가 아니라 found로 써요<br>③ has found — has opened  ✗  현재완료는 지금이 기준이에요 (이 문장의 기준은 과거의 알게 된 때)<br>④ found — had opened  ✓  기준인 알게 된 일은 단순과거, 더 먼저 연 일은 과거완료<br>⑤ had found — opened  ✗  순서가 거꾸로: 알게 된 일이 창문을 연 일보다 먼저가 돼요 | 정답은 4번 found와 had opened예요. 1번은 opened만 써서, 창문을 연 일이 알게 된 때보다 더 먼저라는 것을 시제로 나타내지 못해요. 2번처럼 알게 된 일까지 had found로 쓰면 안 돼요. 기준이 되는 과거의 일은 단순과거로 써요. 5번은 순서를 거꾸로 써서, 알게 된 일이 창문을 연 일보다 먼저가 돼요. | 정답 ④ found — had opened |
| 6. 정리 | 12초 | 정답 ④ found — had opened<br><br>기준이 되는 과거 일 → 단순과거 · 그보다 더 먼저 일어난 일 → had + 과거분사 | 정답은 4번이에요. 기억할 것, 기준이 되는 과거의 일은 단순과거로, 그보다 더 먼저 일어난 일은 had와 과거분사로 써요. | 기준은 단순과거, 더 먼저는 과거완료 |

## 원본 해설

```
핵심 규칙: 과거의 한 시점(알게 된 때)을 기준으로 그보다 먼저 끝난 일은 had + 과거분사로 나타내고, 기준 시점의 일은 단순과거로 쓴다.
풀이 순서: ① 우리말에서 두 일의 순서를 가른다. ‘창문을 연 것’이 먼저, ‘알게 된 것’이 나중이다. → ② 나중 일(주절)은 과거형으로, 그보다 먼저 일어난 일(that절)은 had + 과거분사로 쓴다. → ③ ‘과거형 — had + 과거분사’ 순서인 found — had opened를 고른다.
문장별 판정:
정답 판단: 우리말에서 알게 된 일이 기준 시점이고 연 일은 그보다 먼저 끝났으므로 found — had opened가 알맞다.
선택지 분석:
① [오답] 둘째 빈칸 opened: 단순과거이어서 맞지 않는다. 그보다 먼저 끝난 that절의 일은 과거완료 had opened로 쓴다. 따라서 오답이다.
② [오답] 첫째 빈칸 had found: 과거완료이어서 맞지 않는다. 기준 시점인 주절의 일은 단순과거 found로 쓴다. 따라서 오답이다.
③ [오답] 첫째 빈칸 has found: 현재완료이어서 맞지 않는다. 기준 시점인 주절의 일은 단순과거 found로 쓴다. 둘째 빈칸 has opened: 현재완료이어서 맞지 않는다. 그보다 먼저 끝난 that절의 일은 과거완료 had opened로 쓴다. 따라서 오답이다.
④ [정답] 우리말에서 알게 된 일이 기준 시점이고 연 일은 그보다 먼저 끝났으므로 found — had opened가 알맞다. 모든 자리가 알맞으므로 정답이다.
⑤ [오답] 첫째 빈칸 had found: 과거완료이어서 맞지 않는다. 기준 시점인 주절의 일은 단순과거 found로 쓴다. 둘째 빈칸 opened: 단순과거이어서 맞지 않는다. 그보다 먼저 끝난 that절의 일은 과거완료 had opened로 쓴다. 따라서 오답이다.
```
