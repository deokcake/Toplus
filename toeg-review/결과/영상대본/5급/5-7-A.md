# 5-7 — 멀리 있는 여럿을 가리키는 those

- 급·챕터·번호: 5급 · CH 1 대명사 · 7번

| 2. 문제 | 14초 | 다음 우리말을 영어로 바르게 옮긴 것을 고르시오.<br><br>저 신발들은 나의 것이 아니다.<br><br>① This shoes are not mine.<br>② That shoes are not mine.<br>③ These shoes are not mine.<br>④ Those shoes are not mine.<br>⑤ They shoes are not mine. | 다음 우리말을 영어로 바르게 옮긴 것을 고르세요. 저 신발들은 나의 것이 아니다. 먼저 풀어 보세요. 영상을 잠시 멈춰도 좋아요. | 먼저 풀어 보세요 |
| 3. 핵심 규칙 | 28초 | 핵심 규칙<br>가까운 것: this + 단수 명사 (이 ~),  these + 복수 명사 (이 ~들)<br>먼 것: that + 단수 명사 (저 ~),  those + 복수 명사 (저 ~들)<br>명사 없이 ‘나의 것, 너의 것’ → 소유대명사 mine, yours, his, hers, ours, theirs<br>예) This pen is mine, and those pens are yours. (이 펜은 나의 것이고, 저 펜들은 너의 것이에요.) | 명사 앞에서 가까이 있는 것을 가리킬 때는 ‘이’라는 뜻의 this와 these를 써요. 멀리 있는 것은 ‘저’라는 뜻의 that과 those로 가리켜요. 하나일 때는 this와 that, 여럿일 때는 these와 those 뒤에 복수 명사를 써요. 그리고 명사 없이 나의 것, 너의 것이라고 할 때는 mine, yours 같은 소유대명사를 써요. This pen is mine, and those pens are yours. 이 펜은 나의 것이고, 저 펜들은 너의 것이에요. | this·these는 ‘이’, that·those는 ‘저’ |
| 4. 풀이 순서 | 34초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** ‘저’ = 멀리 있는 것 → that, those. ‘이’를 뜻하는 This, These는 지운다. / 강조 `저 신발들은` / 지움 `① This shoes are not mine.`, `③ These shoes are not mine.`<br>**2단계** ‘신발들’ = 여럿 → 하나를 가리키는 That은 복수 shoes 앞에 못 쓴다. / 지움 `② That shoes are not mine.`<br>**3단계** They(그들은)는 명사 앞에 붙여 쓰지 않는다 → 지운다. 남는 것 ④, ‘나의 것’ = mine / 강조 `④ Those shoes are not mine.` / 지움 `⑤ They shoes are not mine.` | 첫째, ‘저 신발들’의 ‘저’는 멀리 있는 것을 가리키니까, ‘이’라는 뜻의 1번 This와 3번 These는 맞지 않아요. 둘째, 신발들은 여럿이라서, 하나를 가리키는 2번 That도 복수 shoes 앞에 쓸 수 없어요. 셋째, 5번 They는 ‘그들은’이라는 뜻의 주격 대명사라서 명사 앞에 붙여 쓰지 않아요. 남는 4번은 나의 것도 소유대명사 mine으로 바르게 썼어요. Those shoes are not mine. 저 신발들은 나의 것이 아니에요. | ‘저’ → 여럿 → Those |
| 5. 선택지 확인 | 26초 | ① This shoes are not mine.  ✗  This는 ‘이’, 하나 → ‘저 신발들’과 맞지 않아요<br>② That shoes are not mine.  ✗  That은 하나를 가리켜요 → 복수 shoes 앞에 못 써요<br>③ These shoes are not mine.  ✗  These는 ‘이 ~들’ → ‘저’와 달라요<br>④ Those shoes are not mine.  ✓  멀리 있는 여럿 → Those shoes, ‘나의 것’ → mine<br>⑤ They shoes are not mine.  ✗  They(그들은)는 명사 앞에 붙여 쓰지 않아요 | 정답은 4번이에요. 3번 These는 여럿을 가리키지만 ‘이 신발들’이라는 뜻이라서 저 신발들과 달라요. 2번 That은 ‘저’라는 뜻은 맞지만 하나를 가리켜서 복수 shoes 앞에 쓸 수 없어요. 5번 They는 ‘그들은’이라는 뜻이라서 명사 앞에 붙여 쓰지 않아요. | 정답 ④ Those shoes |
| 6. 정리 | 10초 | 정답 ④ Those shoes are not mine.<br><br>‘저 ~들’ → those + 복수 명사,  ‘이 ~들’ → these + 복수 명사 | 정답은 4번이에요. 기억할 것, 멀리 있는 여럿은 those, 가까이 있는 여럿은 these로 가리켜요. | ‘저 ~들’은 those |

## 원본 해설

```
핵심 규칙: 가까운 것은 this(단수)/these(복수), 먼 것은 that(단수)/those(복수)로 가리킨다. ‘~의 것’은 소유대명사(mine, ours, his, hers, theirs)다.
풀이 순서: ① 우리말의 지시어와 명사의 수를 본다: ‘저 신발들’은 멀리 있는 여럿이므로 Those shoes. → ② 동사는 주어의 수에 맞추고 ‘~의 것’은 소유대명사로 쓴다: are not mine. → ③ 정답은 ④.
문장별 판정:
정답 판단: Those + 복수명사 + are not mine으로 바르게 옮겼으므로 정답은 ④이다.
선택지 분석:
① [오답] This는 단수이고 ‘이’라는 뜻이므로 오답이다.
② [오답] That은 단수라 복수 shoes 앞에 쓸 수 없으므로 오답이다.
③ [오답] These는 ‘이 ~들’이라 ‘저’와 맞지 않으므로 오답이다.
④ [정답] Those + 복수명사 + are not mine으로 바르게 옮겼으므로 정답이다.
⑤ [오답] They는 명사 앞에 쓸 수 없으므로 오답이다.
```
