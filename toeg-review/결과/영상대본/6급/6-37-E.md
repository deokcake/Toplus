## 원본 해설

```
핵심 규칙: 일반동사 현재 부정문은 주어+don’t/doesn’t+동사원형으로 만든다.
풀이 순서: ① 빈칸 앞의 doesn't를 본다. 3인칭 단수의 -s는 이미 does에 들어 있다. → ② 그래서 뒤의 동사는 원형이다. runs, to run, running, ran(과거형)을 지운다. → ③ 남는 것은 run.
문장별 판정:
정답 판단: run: doesn’t 뒤의 본동사는 원형 run이다. 따라서 정답은 ②이다.
선택지 분석:
① [오답] runs → run. doesn’t 뒤의 본동사는 원형 run이다. 주어가 3인칭 단수여도 doesn’t 뒤에는 본동사에 s를 다시 붙이지 않는다.
② [정답] run: doesn’t 뒤의 본동사는 원형 run이다.
③ [오답] to run → run. doesn’t 뒤의 본동사는 원형 run이다. to부정사는 이 자리에 쓰지 않는다.
④ [오답] running → run. doesn’t 뒤의 본동사는 원형 run이다. 진행형의 -ing형은 doesn’t 바로 뒤의 본동사 형태가 아니다.
⑤ [오답] ran → run. doesn’t 뒤의 본동사는 원형 run이다. 과거형이 아니라 동사원형을 써야 한다.
```
