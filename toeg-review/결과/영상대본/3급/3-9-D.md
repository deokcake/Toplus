## 원본 해설

```
핵심 규칙: There + be동사 구문에서 there는 형식상 앞에 오는 유도부사이고 실제 주어는 be동사 뒤의 명사이다. be동사의 수·시제는 실제 주어와 때에 맞추며, 의문문은 be동사를 there 앞에 두고 Yes, there is./No, there isn't.처럼 답한다.
풀이 순서: ① There is/are 문장에서 실제 주어는 be동사 뒤의 명사(a meeting)다. there는 주어가 아니다. → ② be동사는 그 명사의 수와 시제에 맞추고, 의문문은 be동사를 there 앞으로 옮긴다. 대답은 Yes, there is(are). / No, there isn't(aren't).다. → ③ 틀린 설명을 지운다: 가(there를 주어로 봄), 나(과거인데 Is를 쓴다고 함). 남은 것을 묶은 다, 라가 정답이다.
문장별 판정:
가 X. 실제 주어는 there가 아니라 a big meeting이다.
나 X. 과거 시점(yesterday)이므로 과거형 Was를 쓴다.
다 O. 단수·과거라 Was이다.
라 O. there를 살려 No, there wasn't.로 답한다.
정답 판단: 옳은 설명은 다, 라이다.
선택지 분석:
① [오답] 가는 옳은 설명이 아니고, 옳은 설명 라를 빠뜨렸다. 따라서 오답이다.
② [정답] 옳은 설명 다, 라를 빠짐없이 골랐으므로 정답이다.
③ [오답] 나는 옳은 설명이 아니고, 옳은 설명 다를 빠뜨렸다. 따라서 오답이다.
④ [오답] 가, 나는 옳은 설명이 아니고, 옳은 설명 라를 빠뜨렸다. 따라서 오답이다.
⑤ [오답] 나는 옳은 설명이 아니다. 따라서 오답이다.
```
