## 원본 해설

```
핵심 규칙: own, know, belong, contain, seem, resemble 같은 상태동사는 보통 진행형으로 쓰지 않는다. 다만 have(먹다), taste(맛보다), think about(곰곰이 생각하다)처럼 동작을 나타낼 때는 진행형을 쓸 수 있다. 또 now, yesterday, last year, tomorrow 같은 시간 표현과 동사의 시제가 맞아야 한다.
풀이 순서: ① 문장마다 두 가지를 본다. 진행형으로 쓴 동사가 상태동사인지, 시간 표현과 시제가 맞는지. → ② is seeming, is having(가지다)은 상태동사의 진행형이라 틀렸고, now + chased, Last night + need는 시제가 어긋난다. → ③ 남는 ④는 상태동사 contain을 현재형으로 썼다.
문장별 판정:
정답 판단: ‘This soup contains too much salt.’은 상태동사(contain)를 단순현재형으로 바르게 썼으므로 정답은 ④이다.
선택지 분석:
① [오답] ‘Look! My dog chased a cat in the yard now.’은 시간 표현(Look!, now)과 동사의 시제가 맞지 않는다. ‘Look! My dog is chasing a cat in the yard now.’로 고쳐야 하므로 오답이다.
② [오답] ‘He is seeming very nervous today.’의 동사 seem: ‘~처럼 보이다’는 상태동사라 진행형으로 쓰지 않는다. ‘He seems very nervous today.’로 고쳐야 하므로 오답이다.
③ [오답] ‘She is having a lot of homework this week.’의 동사 have: ‘가지고 있다’는 뜻일 때 상태동사라 진행형으로 쓰지 않는다. ‘She has a lot of homework this week.’로 고쳐야 하므로 오답이다.
④ [정답] ‘This soup contains too much salt.’은 상태동사(contain)를 단순현재형으로 바르게 썼으므로 정답이다.
⑤ [오답] ‘Last night, we need more chairs for the party.’은 시간 표현(Last night)과 동사의 시제가 맞지 않는다. ‘Last night, we needed more chairs for the party.’로 고쳐야 하므로 오답이다.
```
