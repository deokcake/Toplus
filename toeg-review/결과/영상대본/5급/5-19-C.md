## 원본 해설

```
핵심 규칙: 자음 + y로 끝나는 동사는 y를 i로 바꾸고 -es를 붙인다(study → studies). 모음 + y는 -s만 붙이고(play → plays), -s·-sh·-ch·-x·-o로 끝나면 -es를 붙인다.
풀이 순서: ① <보기>의 동사 원형을 찾는다: study, carry. 둘 다 ‘자음 + y’로 끝나 y를 i로 바꾸고 -es를 붙였다. → ② 보기에서 두 동사가 모두 ‘자음 + y’로 끝나는 묶음을 찾는다. ‘모음 + y’(play, buy)는 -s만 붙이므로 다르다. → ③ 정답은 worry, study.
문장별 판정:
정답 판단: 자음 + y로 끝나 y를 i로 바꾸고 -es를 붙이는 동사들이라 <보기>와 같으므로 정답은 ②이다.
선택지 분석:
① [오답] -s·-sh·-ch·-x·-o로 끝나 -es만 붙이므로 오답이다.
② [정답] 자음 + y로 끝나 y를 i로 바꾸고 -es를 붙이는 동사들이라 <보기>와 같으므로 정답이다.
③ [오답] 모음 + y로 끝나 -s만 붙이므로 오답이다.
④ [오답] -s·-sh·-ch·-x·-o로 끝나 -es만 붙이므로 오답이다.
⑤ [오답] -s만 붙이는 동사들이므로 오답이다.
```
