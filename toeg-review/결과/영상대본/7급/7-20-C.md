## 원본 해설

```
핵심 규칙: this·that은 한 개, these·those는 여러 개를 가리킨다. these/those 뒤에는 are와 복수 명사를, this/that 뒤에는 is와 단수 명사를 쓴다.
풀이 순서: ① 문장마다 지시어(this/that/these/those), be동사, 명사를 차례로 본다. → ② 셋의 수(하나/여럿)가 모두 같은지 견준다. → ③ 선택지 ③ This(하나) + are + books(여럿)라 맞지 않는다. 정답은 ③.
문장별 판정:
정답 판단: 여러 권(books)이고, This가 아니라 These를 써야 하므로 정답은 ③이다.
선택지 분석:
① [오답] 지시 표현, be동사, 명사의 수가 모두 맞으므로 오답이다.
② [오답] 지시 표현, be동사, 명사의 수가 모두 맞으므로 오답이다.
③ [정답] 여러 권(books)이고, This가 아니라 These를 써야 하므로 정답이다.
④ [오답] 지시 표현, be동사, 명사의 수가 모두 맞으므로 오답이다.
⑤ [오답] 선생님의 칭찬으로 어법상 틀린 곳이 없으므로 오답이다.
```
