# 3-2 — 시제와 수에 맞는 There + be동사

- 급·챕터·번호: 3급 · CH 1 be동사 · 2번
- 정답: ⑤
- 총 길이: 133초
- 화면: 칠판에 분필로 판서하듯 ‘판서 순서’대로 한 줄씩 써 나간다. 강조 = 노란 분필, 지움 = 분필 줄 긋기.

| 1. 도입 | 11초 | 3급 · CH 1 be동사 · 2번<br><br>이 문제는 Last year와 뒤에 오는 명사를 보고 There 뒤에 알맞은 be동사를 고르는 문제예요. | 3급 챕터 1, 2번. 이 문제는 Last year와 뒤에 오는 명사를 보고 There 뒤에 알맞은 be동사를 고르는 문제예요. | There 뒤 be동사 고르기 |
| 2. 문제 | 18초 | 다음 문장의 빈칸에 알맞은 표현을 고르시오.<br><br>Last year, _____ many students in the classroom.<br><br>① There is<br>② There are<br>③ There am<br>④ There was<br>⑤ There were | 다음 문장의 빈칸에 알맞은 표현을 고르세요. Last year, 빈칸 many students in the classroom. 먼저 풀어 보세요. 영상을 잠시 멈춰도 좋아요. | 먼저 풀어 보세요 |
| 3. 핵심 규칙 | 31초 | 핵심 규칙<br>There + be동사 + 명사 = ‘~이 있다’, ‘~이 있었다’<br>There 뒤 be동사는 뒤에 오는 명사의 수에 맞춰요: 단수 → is, was / 복수 → are, were<br>시제에도 맞춰요: 현재 → is, are / 과거 → was, were<br>셀 수 없는 명사(milk, money)는 단수로 취급해요<br>예) There were two dogs in the park. (공원에 개가 두 마리 있었어요.) | There 뒤에 be동사와 명사를 쓰면 어디에 무엇이 있다, 또는 있었다는 뜻이에요. 이때 be동사는 뒤에 오는 명사가 단수이면 is나 was, 복수이면 are나 were를 쓰고, milk처럼 셀 수 없는 명사는 단수로 취급해요. 또 현재이면 is나 are, 과거이면 was나 were를 써요. 예를 들어 There were two dogs in the park. 공원에 개가 두 마리 있었어요. | 시제와 뒤 명사의 수에 맞춰요 |
| 4. 풀이 순서 | 32초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** Last year = 작년 → 과거. 현재형 is, are, am이 든 ①②③을 지운다. / 강조 `Last year` / 지움 `① There is`, `② There are`, `③ There am`<br>**2단계** many students = 여러 명 → 복수. 단수 명사 앞에 쓰는 There was를 지운다. / 강조 `many students` / 지움 `④ There was`<br>**3단계** 과거 + 복수 → There were / 강조 `⑤ There were` | 첫째, Last year는 작년이라는 뜻이라 과거이므로, 현재형 is, are, am이 들어간 1번, 2번, 3번을 지워요. 둘째, 뒤에 오는 명사 many students는 학생 여러 명이라 복수이므로, 단수일 때 쓰는 4번 There was도 지워요. 셋째, 남는 것은 5번 There were예요. Last year, there were many students in the classroom. 작년에 교실에는 학생이 많이 있었어요. | 과거 → 복수 → There were |
| 5. 선택지 확인 | 28초 | ① There is  ✗  is는 현재형이고 단수 명사 앞에 써요<br>② There are  ✗  복수는 맞지만 are는 현재형이에요 (Last year)<br>③ There am  ✗  am은 주어 I에만 써요<br>④ There was  ✗  과거는 맞지만 was는 단수 명사 앞에 써요 (many students)<br>⑤ There were  ✓  과거 + 복수 many students | 정답은 5번 There were예요. 2번 There are는 many students가 복수라서 고르기 쉽지만, 현재형이라 Last year와 맞지 않아요. 4번 There was는 과거형이지만, 뒤의 명사가 단수일 때 쓰는 꼴이라 복수 many students와 맞지 않아요. 1번 There is는 현재형인 데다 단수 명사 앞에 써서 두 가지가 다 틀렸어요. | 정답 ⑤ There were |
| 6. 정리 | 13초 | 정답 ⑤ There were<br><br>There + be동사는 시제와 뒤 명사의 수에 맞춰요: 과거 + 복수 → There were | 정답은 5번이에요. 기억할 것, There 뒤의 be동사는 시제와 뒤에 오는 명사의 수에 맞춰요. 과거이고 복수이면 There were를 써요. | 과거·복수 → There were |

## 원본 해설

```
핵심 규칙: There is/are, There was/were의 be동사는 시제와 뒤에 오는 명사의 수에 맞춘다. 셀 수 없는 명사는 단수로 취급한다.
풀이 순서: ① 문장 앞의 시간 표현으로 시제를 정한다(Last year → 과거). → ② There 뒤 be동사는 뒤에 오는 명사에 수를 맞춘다(many students, 복수). → ③ 정답은 There were.
문장별 판정:
정답 판단: 과거이고 뒤의 명사가 복수이므로 There were가 알맞으므로 정답은 ⑤이다.
선택지 분석:
① [오답] 과거의 일이고 뒤의 명사도 복수라 is를 쓸 수 없으므로 오답이다.
② [오답] Last year가 있어 현재형 are를 쓸 수 없으므로 오답이다.
③ [오답] There am이라는 표현은 없으므로 오답이다.
④ [오답] 뒤의 명사 many students가 복수라 was를 쓸 수 없으므로 오답이다.
⑤ [정답] 과거이고 뒤의 명사가 복수이므로 There were가 알맞으므로 정답이다.
```
