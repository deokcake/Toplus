## 원본 해설

```
핵심 규칙: 가까운 것은 this(단수)/these(복수), 먼 것은 that(단수)/those(복수)로 가리킨다. ‘~의 것’은 소유대명사(mine, ours, his, hers, theirs)다.
풀이 순서: ① 우리말의 지시어와 명사의 수를 본다: ‘이 책들’은 가까이 있는 여럿이므로 These books. → ② 동사는 주어의 수에 맞추고 ‘~의 것’은 소유대명사로 쓴다: are ours. → ③ 정답은 ⑤.
문장별 판정:
정답 판단: 가까운 복수 대상은 These books, 복수 be동사는 are, ‘우리의 것’은 ours이므로 These books are ours.가 알맞다. 따라서 정답은 ⑤이다.
선택지 분석:
① [오답] 복수 books 앞에서는 This 대신 These를 쓴다. 또한 뒤에 명사가 없는 ‘우리의 것’은 소유대명사 ours이므로 our를 ours로 고친다.
② [오답] 주어는 These books이며 복수형에 맞는 are가 그 뒤에 온다. These books are ours.로 고친다.
③ [오답] Those는 먼 대상을 가리키므로 ‘이’와 다르다. 복수 These books와 are를 써서 These books are ours.로 고친다.
④ [오답] 명사 없이 ‘우리의 것’을 나타내는 소유대명사 ours가 필요하다. our는 뒤에 명사를 직접 꾸밀 때 쓰는 소유격이다.
⑤ [정답] 가까운 복수 대상은 These books, 복수 be동사는 are, ‘우리의 것’은 ours이므로 These books are ours.가 알맞다.
```
