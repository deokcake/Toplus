## 원본 해설

```
핵심 규칙: 상태를 나타내는 동사(know, believe, own, need, resemble 등)는 보통 진행형으로 쓰지 않고 단순현재로 쓴다. 상태동사도 특정 의미·문맥에서는 진행형으로 쓰일 수 있으므로 진행형을 언제나 비문이라고 단정하지 않는다. 단순현재형은 주어와 수를 일치시킨다.
풀이 순서: ① 밑줄의 동사(own)가 동작인지 상태인지 본다. ‘소유하다’는 상태를 나타내므로 진행형으로 쓰지 않는다. → ② 진행형을 단순현재로 고친다. be동사 + 동사원형, 수동태, -ing만 남긴 보기는 지운다. → ③ 주어(We)에 수를 맞추면 own이다.
문장별 판정:
정답 판단: 주어 We에 맞는 own의 단순현재형은 own이다. 완성문: We own this apartment.
선택지 분석:
① [오답] owning만으로는 문장의 정형동사가 되지 않는다. 단순현재 동사가 필요하다. 완성문: We own this apartment.
② [정답] 주어 We에 맞는 own의 단순현재형은 own이다. 완성문: We own this apartment.
③ [오답] are owned는 수동형이다. 주어가 직접 느끼거나 알고 소유하는 원문의 능동 상태를 나타내지 않는다. 완성문: We own this apartment.
④ [오답] be동사 are와 동사원형 own을 이렇게 직접 연결할 수 없다. 완성문: We own this apartment.
⑤ [오답] 단순현재 동사의 수를 주어 We에 맞추면 own이다. owns는 주어와 일치하지 않는다. 완성문: We own this apartment.
```
