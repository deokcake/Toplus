| 5. 선택지 확인 | 22초 | ① There are  ✗  현재는 맞지만 are는 복수 명사 앞에 써요 (a new message)<br>② There were  ✗  were는 과거형이고 복수 명사 앞에 써요<br>③ There was  ✗  단수는 맞지만 was는 과거형이에요 (Right now)<br>④ There is  ✓  현재 + 단수 a new message<br>⑤ There am  ✗  am은 주어 I에만 써요 | 정답은 4번 There is예요. 1번 There are는 현재형이라 고르기 쉽지만, 뒤의 명사가 복수일 때 쓰는 꼴이라 단수 a new message와 맞지 않아요. 3번 There was는 단수 명사 앞에 쓰지만, 과거형이라 Right now와 맞지 않아요. | 정답 ④ There is |

## 원본 해설

```
핵심 규칙: there 구문은 뒤의 실제 명사구의 수와 문장의 시제에 맞춰 there is/are/was/were를 선택한다.
풀이 순서: ① 문장 앞의 시간 표현으로 시제를 정한다(Right now → 현재). → ② There 뒤 be동사는 뒤에 오는 명사에 수를 맞춘다(a new message, 단수). → ③ 정답은 There is.
문장별 판정:
정답 판단: Right now는 현재를 나타내고 a new message는 단수이므로 There is가 맞다. 따라서 정답은 ④이다.
선택지 분석:
① [오답] are는 복수형이므로 단수 명사구 a new message와 수가 맞지 않는다.
② [오답] were는 과거형이므로 현재를 나타내는 Right now와 맞지 않는다. were는 복수형이므로 단수 명사구 a new message와 수가 맞지 않는다.
③ [오답] was는 과거형이므로 현재를 나타내는 Right now와 맞지 않는다.
④ [정답] Right now는 현재를 나타내고 a new message는 단수이므로 There is가 맞다.
⑤ [오답] am은 주어 I에 쓰는 형태로, 이 there 구문의 명사구와 결합하지 않는다.
```
