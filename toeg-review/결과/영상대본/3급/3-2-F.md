# 3-2 F 유형 — 시제와 수에 맞는 There + be동사

- 급·챕터·번호: 3급 · CH 1 be동사 · 2번 · F 유형
- 정답: ④
- 총 길이: 134초
- 화면: 칠판에 분필로 판서하듯 ‘판서 순서’대로 한 줄씩 써 나간다. 강조 = 노란 분필, 지움 = 분필 줄 긋기.

| 2. 문제 | 18초 | 다음 문장의 빈칸에 알맞은 표현을 고르시오.<br><br>Last night, _____ many cars on the road.<br><br>① There is<br>② There are<br>③ There am<br>④ There were<br>⑤ There was | 다음 문장의 빈칸에 알맞은 표현을 고르세요. Last night, 빈칸 many cars on the road. 먼저 풀어 보세요. 영상을 잠시 멈춰도 좋아요. | 먼저 풀어 보세요 |
| 3. 핵심 규칙 | 31초 | 핵심 규칙<br>There + be동사 + 명사 = ‘~이 있다’, ‘~이 있었다’<br>There 뒤 be동사는 뒤에 오는 명사의 수에 맞춰요: 단수 → is, was / 복수 → are, were<br>시제에도 맞춰요: 현재 → is, are / 과거 → was, were<br>셀 수 없는 명사(milk, money)는 단수로 취급해요<br>예) There were many birds in the tree. (나무에 새가 많이 있었어요.) | There 뒤에 be동사와 명사를 쓰면 어디에 무엇이 있다, 또는 있었다는 뜻이에요. 이때 be동사는 뒤에 오는 명사가 단수이면 is나 was, 복수이면 are나 were를 쓰고, milk처럼 셀 수 없는 명사는 단수로 취급해요. 또 현재이면 is나 are, 과거이면 was나 were를 써요. 예를 들어 There were many birds in the tree. 나무에 새가 많이 있었어요. | 시제와 뒤 명사의 수에 맞춰요 |
| 4. 풀이 순서 | 32초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** Last night = 어젯밤 → 과거. 현재형 is, are, am이 든 ①②③을 지운다. / 강조 `Last night` / 지움 `① There is`, `② There are`, `③ There am`<br>**2단계** many cars = 여러 대 → 복수. 단수 명사 앞에 쓰는 There was를 지운다. / 강조 `many cars` / 지움 `⑤ There was`<br>**3단계** 과거 + 복수 → There were / 강조 `④ There were` | 첫째, Last night는 어젯밤이라는 뜻이라 과거이므로, 현재형 is, are, am이 들어간 1번, 2번, 3번을 지워요. 둘째, 뒤에 오는 명사 many cars는 자동차 여러 대라 복수이므로, 단수일 때 쓰는 5번 There was도 지워요. 셋째, 남는 것은 4번 There were예요. Last night, there were many cars on the road. 어젯밤 도로에는 차가 많이 있었어요. | 과거 → 복수 → There were |
| 5. 선택지 확인 | 28초 | ① There is  ✗  is는 현재형이고 단수 명사 앞에 써요<br>② There are  ✗  복수는 맞지만 are는 현재형이에요 (Last night)<br>③ There am  ✗  am은 주어 I에만 써요<br>④ There were  ✓  과거 + 복수 many cars<br>⑤ There was  ✗  과거는 맞지만 was는 단수 명사 앞에 써요 (many cars) | 정답은 4번 There were예요. 5번 There was는 과거형이라 고르기 쉽지만, 뒤의 명사가 단수일 때 쓰는 꼴이라 복수 many cars와 맞지 않아요. 2번 There are는 복수 명사 앞에 쓰지만, 현재형이라 Last night와 맞지 않아요. 1번 There is는 현재형인 데다 단수 명사 앞에 써서 두 가지가 다 틀렸어요. | 정답 ④ There were |
| 6. 정리 | 13초 | 정답 ④ There were<br><br>There + be동사는 시제와 뒤 명사의 수에 맞춰요: 과거 + 복수 → There were | 정답은 4번이에요. 기억할 것, There 뒤의 be동사는 시제와 뒤에 오는 명사의 수에 맞춰요. 과거이고 복수이면 There were를 써요. | 과거·복수 → There were |

## 원본 해설

```
핵심 규칙: there 구문은 뒤의 실제 명사구의 수와 문장의 시제에 맞춰 there is/are/was/were를 선택한다.
풀이 순서: ① 문장 앞의 시간 표현으로 시제를 정한다(Last night → 과거). → ② There 뒤 be동사는 뒤에 오는 명사에 수를 맞춘다(many cars, 복수). → ③ 정답은 There were.
문장별 판정:
정답 판단: Last night는 과거를 나타내고 many cars는 복수이므로 There were가 맞다. 따라서 정답은 ④이다.
선택지 분석:
① [오답] is는 현재형이므로 과거를 나타내는 Last night와 맞지 않는다. is는 단수형이므로 복수 명사구 many cars와 수가 맞지 않는다.
② [오답] are는 현재형이므로 과거를 나타내는 Last night와 맞지 않는다.
③ [오답] am은 주어 I에 쓰는 형태로, 이 there 구문의 명사구와 결합하지 않는다.
④ [정답] Last night는 과거를 나타내고 many cars는 복수이므로 There were가 맞다.
⑤ [오답] was는 단수형이므로 복수 명사구 many cars와 수가 맞지 않는다.
```
