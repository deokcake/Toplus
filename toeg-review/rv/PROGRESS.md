# 전수 감수 진행 상황
방식: 챕터마다 dump.py로 출력 → 모든 변형을 직접 풀이 → rv/g{급}_ch{챕터}.py 에 REVIEW 기록
판정: 적합 / 수정(표기) / 수정(내용) / 부적합. 끝에 '!'가 붙으면 자동 점검 결과를 무시(오탐).
기본값 "*" 은 B~F 공통. 자동 점검의 확실한 결함(문법 단서, 선택지 순서, 유형 간 공유 등)은 조립 단계에서 합쳐진다.
