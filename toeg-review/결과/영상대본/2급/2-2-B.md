# 2-2 B 유형 — 5형식과 1형식 구별하기

- 급·챕터·번호: 2급 · CH 1 문장의 형식 · 2번 · B 유형
- 정답: ⑤
- 총 길이: 125초
- 화면: 칠판에 분필로 판서하듯 ‘판서 순서’대로 한 줄씩 써 나간다. 강조 = 노란 분필, 지움 = 분필 줄 긋기.

| 장면 | 길이 | 화면(판서 순서) | 내레이션 | 자막 |
|---|---|---|---|---|
| 1. 도입 | 11초 | 2급 · CH 1 문장의 형식 · 2번 · B 유형<br><br>이 문제는 목적격 보어가 있는지 따져 5형식이 아닌 문장을 고르는 문제예요. | 2급 챕터 1, 2번 B 유형. 이 문제는 목적격 보어가 있는지 따져 5형식이 아닌 문장을 고르는 문제예요. | 5형식이 아닌 문장 찾기 |
| 2. 문제 | 14초 | 다음 중 5형식 문장이 아닌 것을 고르시오.<br><br>① They elected Jane captain.<br>② We named the puppy Coco.<br>③ I found the lecture boring.<br>④ The news made everyone nervous.<br>⑤ The baby slept peacefully. | 다음 중 5형식 문장이 아닌 것을 고르시오. 먼저 풀어 보세요. 영상을 잠시 멈춰도 좋아요. | 먼저 풀어 보세요 |
| 3. 핵심 규칙 | 30초 | 핵심 규칙<br>5형식 = 주어 + 동사 + 목적어 + 목적격 보어<br>목적격 보어(명사, 형용사, to부정사, 분사 등) → 목적어의 이름·신분·상태·행동을 설명<br>동사 뒤에 목적어·보어 없이 부사(구)만 있으면 → 1형식 (부사는 형식에 세지 않아요)<br>예) The song makes me happy. (그 노래는 나를 행복하게 해요. happy → me의 상태) | 5형식 문장은 주어, 동사, 목적어 뒤에 목적격 보어가 오는 문장이에요. 목적격 보어는 명사, 형용사, to부정사, 분사 같은 말로, 목적어의 이름이나 신분, 상태, 행동을 설명해요. 예를 들어 The song makes me happy. 그 노래는 나를 행복하게 해요. 반면 동사 뒤에 목적어도 보어도 없이 부사나 부사구만 있으면 1형식이에요. | 목적어 + 목적격 보어 = 5형식 |
| 4. 풀이 순서 | 32초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** 5형식이 ‘아닌’ 것 → 문장마다 동사 뒤에 ‘목적어 + 목적어를 설명하는 말’이 있는지 본다. / 강조 `5형식 문장이 아닌 것`<br>**2단계** captain = Jane의 신분, Coco = the puppy의 이름, boring·nervous = 상태 → ①~④ 모두 5형식 / 강조 `Jane captain`, `the puppy Coco`, `the lecture boring`, `everyone nervous` / 지움 `① They elected Jane captain.`, `② We named the puppy Coco.`, `③ I found the lecture boring.`, `④ The news made everyone nervous.`<br>**3단계** slept 뒤에 목적어 없음, peacefully = 동사를 꾸미는 부사 → 1형식 / 강조 `slept peacefully` | 첫째, 문장마다 동사 뒤에 목적어와 그 목적어를 설명하는 말이 함께 있는지 봐요. 둘째, 1번 captain은 Jane의 신분을, 2번 Coco는 the puppy의 이름을, 3번 boring과 4번 nervous는 the lecture와 everyone의 상태를 나타내요. 그래서 이 네 문장은 모두 5형식이에요. 셋째, 5번은 slept 뒤에 목적어가 없고, peacefully는 동사를 꾸미는 부사라서 1형식이에요. | 보어 확인 → 부사만 → ⑤ |
| 5. 선택지 확인 | 28초 | ① They elected Jane captain.  ✗  captain이 Jane의 신분(주장) → 5형식<br>② We named the puppy Coco.  ✗  Coco가 the puppy의 이름 → 5형식<br>③ I found the lecture boring.  ✗  boring이 the lecture의 상태 → 5형식<br>④ The news made everyone nervous.  ✗  nervous가 everyone의 상태 → 5형식<br>⑤ The baby slept peacefully.  ✓  slept 뒤에 부사 peacefully만 → 1형식 | 정답은 5번 The baby slept peacefully, 아기가 평화롭게 잤다는 문장이에요. 2번은 명사가 두 개 이어져 4형식처럼 보이지만, the puppy가 곧 Coco라서 Coco는 이름을 나타내는 목적격 보어예요. 3번 found는 여기서 강의가 지루하다고 느꼈다는 뜻이고, boring이 the lecture의 상태를 설명하는 5형식이에요. | 정답 ⑤ (1형식) |
| 6. 정리 | 10초 | 정답 ⑤ The baby slept peacefully.<br><br>목적어 + 목적격 보어 → 5형식, 동사 뒤에 부사(구)만 → 1형식 | 정답은 5번이에요. 기억할 것, 목적어 뒤에 그 목적어를 설명하는 목적격 보어가 있어야 5형식이에요. | 목적어 + 목적격 보어 → 5형식 |

## 원본 해설

```
핵심 규칙: 5형식은 S+V+O+OC이며 목적격보어는 목적어의 상태·신분·행동을 설명한다. 관사와 명사를 분리하지 않고 목적어 명사구 전체를 하나의 성분으로 본다.
풀이 순서: ① 문장마다 동사 뒤에 ‘목적어 + 목적어를 설명하는 말’이 이어지는지 본다. → ② 목적어 뒤의 말이 목적어의 이름·상태·행동을 나타내면 5형식이다. → ③ 선택지 ⑤는 slept 뒤에 목적어 없이 부사 peacefully만 있는 1형식이다. 5형식이 아니다.
문장별 판정:
정답 판단: ‘The baby slept peacefully’는 The baby(S) + slept(V) + 부사어의 1형식이다. 뒤의 표현이 있다면 부사어로 핵심 형식에 포함되지 않는다. 목적격보어가 없으므로 5형식이 아니다. 따라서 5형식이 아닌 선택지로 정답이다.
선택지 분석:
① [오답] ‘They elected Jane captain’은 They(S) + elected(V) + Jane(O) + captain(OC)의 5형식이다. 목적격보어가 목적어의 상태·신분·행동을 설명한다. 목적어와 목적격보어가 모두 있으므로 5형식이다. 5형식 문장이므로 오답이다.
② [오답] ‘We named the puppy Coco’는 We(S) + named(V) + the puppy(O) + Coco(OC)의 5형식이다. 목적격보어가 목적어의 상태·신분·행동을 설명한다. 목적어와 목적격보어가 모두 있으므로 5형식이다. 5형식 문장이므로 오답이다.
③ [오답] ‘I found the lecture boring’은 I(S) + found(V) + the lecture(O) + boring(OC)의 5형식이다. 목적격보어가 목적어의 상태·신분·행동을 설명한다. 목적어와 목적격보어가 모두 있으므로 5형식이다. 5형식 문장이므로 오답이다.
④ [오답] ‘The news made everyone nervous’는 The news(S) + made(V) + everyone(O) + nervous(OC)의 5형식이다. 목적격보어가 목적어의 상태·신분·행동을 설명한다. 목적어와 목적격보어가 모두 있으므로 5형식이다. 5형식 문장이므로 오답이다.
⑤ [정답] ‘The baby slept peacefully’는 The baby(S) + slept(V) + 부사어의 1형식이다. 뒤의 표현이 있다면 부사어로 핵심 형식에 포함되지 않는다. 목적격보어가 없으므로 5형식이 아니다. 발문이 요구한 5형식이 아닌 문장이므로 정답이다.
```
