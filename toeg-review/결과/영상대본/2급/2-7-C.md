# 2-7 C 유형 — 1형식 문장으로만 된 짝 고르기

- 급·챕터·번호: 2급 · CH 1 문장의 형식 · 7번 · C 유형
- 정답: ③
- 총 길이: 138초
- 화면: 칠판에 분필로 판서하듯 ‘판서 순서’대로 한 줄씩 써 나간다. 강조 = 노란 분필, 지움 = 분필 줄 긋기.

|---|---|---|---|---|
| 1. 도입 | 11초 | 2급 · CH 1 문장의 형식 · 7번 · C 유형<br><br>이 문제는 동사 뒤에 오는 말을 살펴, 두 문장이 모두 1형식인 짝을 고르는 문제예요. | 2급 챕터 1, 7번 C 유형. 이 문제는 동사 뒤에 오는 말을 살펴, 두 문장이 모두 1형식인 짝을 고르는 문제예요. | 1형식 문장으로만 된 짝 |
| 2. 문제 | 14초 | 다음 중 1형식 문장으로만 짝지어진 것은?<br><br>① Tom has a bike. / The bus came.<br>② Jane looks tired. / They ran fast.<br>③ The children ran outside. / The bell rang suddenly.<br>④ The food smells nice. / Birds flew.<br>⑤ We kept the door open. / He slept. | 다음 중 1형식 문장으로만 짝지어진 것은? 먼저 풀어 보세요. 영상을 잠시 멈춰도 좋아요. | 먼저 풀어 보세요 |
| 3. 핵심 규칙 | 30초 | 핵심 규칙<br>1형식 = 주어 + 동사 (이것만으로 뜻이 완성돼요)<br>동사 뒤의 부사·부사구(어떻게, 언제, 어디서)는 형식에 세지 않아요<br>동사 뒤에 주어의 상태·신분을 설명하는 보어 → 2형식, 목적어 → 3·4·5형식<br>예) The plane landed safely. (비행기가 안전하게 착륙했어요.) | 1형식은 주어와 동사만으로 뜻이 완성되는 문장으로, 뒤에 부사나 부사구가 붙어도 1형식이에요. 하지만 동사 뒤에 주어의 상태나 신분을 설명하는 보어가 오면 2형식, 목적어가 오면 3, 4, 5형식이에요. 예를 들어 The plane landed safely. 비행기가 안전하게 착륙했어요. safely는 방법을 나타내는 부사라서 1형식이에요. | 1형식 = 주어 + 동사 |
| 4. 풀이 순서 | 42초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** 목적어가 있는 문장 → ① has a bike (3형식), ⑤ kept the door open (목적어 + 목적격 보어, 5형식). 지운다. / 강조 `has a bike`, `kept the door open` / 지움 `① Tom has a bike. / The bus came.`, `⑤ We kept the door open. / He slept.`<br>**2단계** 주어를 설명하는 형용사 보어 → ② looks tired, ④ smells nice (2형식). 지운다. / 강조 `looks tired`, `smells nice` / 지움 `② Jane looks tired. / They ran fast.`, `④ The food smells nice. / Birds flew.`<br>**3단계** 남는 것은 ③ → outside(밖으로), suddenly(갑자기)는 부사 → 둘 다 1형식 / 강조 `The children ran outside.`, `The bell rang suddenly.` | 첫째, 1번 has 뒤의 a bike는 목적어라서 3형식이고, 5번은 목적어 the door 뒤에 그 상태를 설명하는 목적격 보어 open이 있어서 5형식이에요. 둘째, 2번 tired와 4번 nice는 주어의 상태를 설명하는 형용사 보어라서, looks tired와 smells nice가 있는 문장은 2형식이에요. 셋째, 남은 3번의 outside는 밖으로, suddenly는 갑자기라는 뜻의 부사라서 두 문장 모두 1형식이에요. The children ran outside. 아이들이 밖으로 뛰어나갔어요. The bell rang suddenly. 종이 갑자기 울렸어요. | 목적어·보어 있는 짝 지우기 |
| 5. 선택지 확인 | 30초 | ① Tom has a bike. / The bus came.  ✗  a bike는 has의 목적어 → 3형식<br>② Jane looks tired. / They ran fast.  ✗  tired는 주어 Jane을 설명하는 보어 → 2형식<br>③ The children ran outside. / The bell rang suddenly.  ✓  outside, suddenly는 부사 → 둘 다 1형식<br>④ The food smells nice. / Birds flew.  ✗  nice는 주어를 설명하는 보어 → 2형식<br>⑤ We kept the door open. / He slept.  ✗  목적어 the door + 목적격 보어 open → 5형식 | 정답은 3번이에요. 2번을 고르기 쉬운데, ran fast의 fast는 빨리라는 부사라서 뒤 문장은 1형식이 맞아요. 하지만 Jane looks tired. 제인이 피곤해 보인다는 뜻인데, tired는 주어 Jane의 상태를 설명하는 보어라서 2형식이에요. 4번도 smells nice의 nice가 주어를 설명하는 보어라서, 1형식으로만 된 짝이 아니에요. | 정답 ③ ran outside, rang suddenly |
| 6. 정리 | 11초 | 정답 ③ The children ran outside. / The bell rang suddenly.<br><br>보어·목적어 없이 주어 + 동사 (+ 부사·부사구) → 1형식 | 정답은 3번이에요. 기억할 것, 보어나 목적어 없이 주어와 동사만 있으면, 부사나 부사구가 붙어도 1형식이에요. | 부사·부사구만 → 1형식 |

## 원본 해설

```
핵심 규칙: 1형식의 핵심 구조는 S+V이며 장소·시간·방법 부사어는 목적어나 보어로 세지 않는다. 연결동사 뒤 주어의 성질은 주격보어이고 타동사 뒤 대상은 목적어이다.
풀이 순서: ① 문장마다 동사 뒤의 말이 부사(구)인지, 보어·목적어인지 가른다. 부사(구)는 형식에 들어가지 않는다. → ② 한 쌍에서 한 문장이라도 보어나 목적어가 있으면 지운다: ① has a bike, ② looks tired, ④ smells nice, ⑤ kept the door open. → ③ 두 문장 모두 ‘주어 + 동사(+ 부사)’인 ③이 정답이다.
문장별 판정:
정답 판단: The children(S)+ran(V), The bell(S)+rang(V)로 둘 다 1형식이다. outside와 suddenly는 부사이다.
선택지 분석:
① [오답] Tom(S)+has(V)+a bike(O)는 3형식, The bus(S)+came(V)는 1형식이다.
② [오답] Jane(S)+looks(V)+tired(C)는 2형식, They(S)+ran(V)는 1형식이다.
③ [정답] The children(S)+ran(V), The bell(S)+rang(V)로 둘 다 1형식이다. outside와 suddenly는 부사이다.
④ [오답] The food(S)+smells(V)+nice(C)는 2형식, Birds(S)+flew(V)는 1형식이다.
⑤ [오답] We(S)+kept(V)+the door(O)+open(OC)는 5형식, He(S)+slept(V)는 1형식이다.
```
