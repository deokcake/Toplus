## 원본 해설

```
핵심 규칙: 불규칙동사는 과거형을 따로 외운다. -ed를 붙이면 틀린다(give - gave, fly - flew, catch - caught, leave - left).
풀이 순서: ① 묶음마다 세 동사의 과거형을 하나씩 확인한다. 불규칙동사에 -ed를 붙인 것이 하나라도 있으면 지운다. → ② gived(gave), flied(flew), catched(caught), leaved(left)가 틀렸다. → ③ 세 개가 모두 옳은 ①이 정답이다.
문장별 판정:
정답 판단: run - ran, speak - spoke, take - took가 모두 옳으므로 정답은 ①이다.
선택지 분석:
① [정답] run - ran, speak - spoke, take - took가 모두 옳으므로 정답이다.
② [오답] give의 과거형은 gave이므로 오답이다.
③ [오답] fly의 과거형은 flew이므로 오답이다.
④ [오답] catch의 과거형은 caught이므로 오답이다.
⑤ [오답] leave의 과거형은 left이므로 오답이다.
```
