## 원본 해설

```
핵심 규칙: 3인칭 단수 주어의 현재 부정문은 does not(doesn't) + 동사원형으로 만든다.
풀이 순서: ① 동사(drinks)가 일반동사의 현재형이다. 부정문은 do/does + not + 동사원형이다. → ② 주어(She, 3인칭 단수)에 맞춰 does not을 쓴다. 본동사는 원형(drink)으로 되돌린다. → ③ 정답은 ⑤.
문장별 판정:
정답 판단: does not + 동사원형으로 바르게 바꿨으므로 정답은 ⑤이다.
선택지 분석:
① [오답] 3인칭 단수 주어(She)에는 does not을 쓰므로 오답이다.
② [오답] does not 뒤에는 동사원형(drink)을 쓰므로 오답이다.
③ [오답] 일반동사 문장에는 be동사로 부정문을 만들지 않으므로 오답이다.
④ [오답] not만 넣어서는 부정문이 되지 않으므로 오답이다.
⑤ [정답] does not + 동사원형으로 바르게 바꿨으므로 정답이다.
```
