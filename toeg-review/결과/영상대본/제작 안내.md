# TOEG 풀이 영상 대본 — 제작 안내

문항 하나에 영상 한 편입니다(원문항 A와 변형 B~F 모두, 7급~1급). 영상마다 그 문항만 보고도 규칙을 처음부터 끝까지 배울 수 있도록 썼고, 다른 영상을 가리키는 말은 넣지 않았습니다.

## 파일
| 파일 | 내용 |
|---|---|
| `영상대본_<급>급.zip` | 문항마다 `<급>-<번호>-<유형>.json`(제작 도구용)과 `.md`(사람이 읽는 표) |
| `<급>급_대본.md` | 그 급의 대본 전체를 한 파일로 |
| `영상대본_전체.xlsx` | ‘영상 목록’(한 줄 = 한 편), ‘장면’(한 줄 = 한 장면: 화면 글, 판서 순서, 풀이 단계, 내레이션, 자막) |

## 영상 구성 (6장면, 1분 30초~2분 20초)
1. **도입** — “N급 챕터 M, K번. 이 문제는 ○○을 묻는 문제예요.”
2. **문제** — 문항 전체를 칠판에 쓰고 발문과 문장을 읽은 뒤 “먼저 풀어 보세요. 영상을 잠시 멈춰도 좋아요.”
3. **핵심 규칙** — 규칙(형태·쓰임)과 예문 하나(우리말 뜻)를 판서하며 설명
4. **풀이 순서** — 문제 판서 위에 단계마다 강조(노란 분필)·지움(줄 긋기)을 더하며 풀이
5. **선택지 확인** — 보기마다 ✓/✗와 짧은 이유, 학생이 고를 만한 오답 2~3개를 말로 설명
6. **정리** — 정답 번호와 기억할 규칙 한 줄

## 화면: 칠판 판서
- 짙은 녹색 칠판, 흰 분필 글씨. 강조는 노란 분필(밑줄·동그라미), 지움은 분필 줄 긋기, ✓/✗는 분필 표시.
- 글은 한꺼번에 뜨지 않고 사람이 쓰듯 한 줄씩 나타납니다: `screen.reveal` 목록 순서대로, 내레이션 문장에 맞춰 씁니다.
- 장면이 바뀌면 칠판을 지우고 새로 씁니다. 장면 4는 장면 2의 판서를 그대로 두고 `screen.steps`의 단계마다 강조·지움만 더합니다.
- `<u>…</u>`는 밑줄로 씁니다.

## JSON 읽는 법 (`scenes[]`)
| 필드 | 뜻 |
|---|---|
| `no`, `name`, `sec` | 장면 번호·이름·길이(초). 음성이 더 길면 음성 길이에 맞춥니다 |
| `screen.text` | 칠판에 쓸 글 전체 |
| `screen.reveal` | 판서 순서(줄 단위) |
| `screen.steps[]` | 장면 4의 단계: `note`(판서 메모), `highlight`(강조할 조각), `strike`(지울 조각) |
| `screen.marks` | 장면 5의 보기별 ✓/✗ |
| `narration` | 읽을 말(TTS용으로 기호를 말로 바꿔 두었습니다. 영어는 영어 그대로 읽습니다) |
| `caption` | 화면 아래 짧은 자막 |
| `source` | 원래 문항·정답·해설(확인용) |

## AI 도구에 맡길 때 쓰는 지시문 예시
> 아래 JSON은 영어 문법 풀이 영상 한 편의 대본이다. 1920×1080, 짙은 녹색 칠판 배경에 손글씨 분필 글씨로, 사람이 판서하듯 `screen.reveal` 순서대로 한 줄씩 써 나가는 영상을 만들어 줘. 장면마다 `narration`을 한국어 여성(또는 남성) 목소리로 읽고(영어 문장은 영어 발음으로), 내레이션 문장에 맞춰 판서가 진행되게 해 줘. 장면 4는 장면 2의 판서를 지우지 말고 `steps`마다 `highlight`는 노란 분필 밑줄, `strike`는 줄 긋기로 더해 줘. 장면 5는 보기 줄 끝에 ✓/✗를 분필로 그려 줘. 화면 아래에 `caption`을 자막으로 넣어 줘. 장면 길이는 `sec`를 기준으로 하되 음성이 길면 음성에 맞춰 줘.
> (JSON 붙여넣기)
