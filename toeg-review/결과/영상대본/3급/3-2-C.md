# 3-2 C 유형 — 시제와 수에 맞는 There + be동사

- 급·챕터·번호: 3급 · CH 1 be동사 · 2번 · C 유형

## 원본 해설

```
핵심 규칙: there 구문은 뒤의 실제 명사구의 수와 문장의 시제에 맞춰 there is/are/was/were를 선택한다.
풀이 순서: ① 문장 앞의 시간 표현으로 시제를 정한다(Yesterday → 과거). → ② There 뒤 be동사는 뒤에 오는 명사에 수를 맞춘다(a cat, 단수). → ③ 정답은 There was.
문장별 판정:
정답 판단: Yesterday는 과거를 나타내고 a cat은 단수이므로 There was가 맞다. 따라서 정답은 ②이다.
선택지 분석:
① [오답] am은 주어 I에 쓰는 형태로, 이 there 구문의 명사구와 결합하지 않는다.
② [정답] Yesterday는 과거를 나타내고 a cat은 단수이므로 There was가 맞다.
③ [오답] are는 현재형이므로 과거를 나타내는 Yesterday와 맞지 않는다. are는 복수형이므로 단수 명사구 a cat과 수가 맞지 않는다.
④ [오답] were는 복수형이므로 단수 명사구 a cat과 수가 맞지 않는다.
⑤ [오답] is는 현재형이므로 과거를 나타내는 Yesterday와 맞지 않는다.
```
