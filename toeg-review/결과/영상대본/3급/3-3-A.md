## 원본 해설

```
핵심 규칙: be동사 의문문은 ‘be동사 + 주어 ~?’이고, 대답은 ‘Yes, 주어 + be동사.’ / ‘No, 주어 + be동사 + not.’이다. 질문의 you는 I로, I는 you로 받는다.
풀이 순서: ① (A)는 의문문 맨 앞의 be동사다. 주어에 맞춘다(you → Are). → ② (B)는 No 뒤의 짧은 대답이다. 질문의 주어를 대명사로 받아 ‘주어 + be동사’를 쓴다(you로 물었으므로 I'm). 뒤에 not이 있으므로 be동사가 꼭 들어가야 한다. → ③ 정답은 ①.
문장별 판정:
정답 판단: 주어 you에는 Are, 대답은 I'm not이므로 정답은 ①이다.
선택지 분석:
① [정답] 주어 you에는 Are, 대답은 I'm not이므로 정답이다.
② [오답] 주어 you에 Is를 쓸 수 없으므로 오답이다.
③ [오답] No, I not에는 be동사가 없으므로 오답이다.
④ [오답] 두 빈칸 모두 맞지 않으므로 오답이다.
⑤ [오답] 주어 you에 Am을 쓸 수 없으므로 오답이다.
```
