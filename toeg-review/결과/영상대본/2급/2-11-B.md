## 원본 해설

```
핵심 규칙: yesterday, last ~처럼 끝난 과거 시점에는 과거형을 쓰고, since ~, for ~ now처럼 과거부터 지금까지 이어지는 기간에는 현재완료(have/has + 과거분사)를 쓴다.
풀이 순서: ① 첫째 빈칸 문장의 시간 표현(last Monday)은 끝난 과거 시점이다. 과거형(ran into)을 쓰고 현재완료는 쓸 수 없다. → ② 둘째 빈칸 문장의 시간 표현(since last winter)은 과거부터 지금까지 이어지는 기간이다. 현재완료(haven't talked to)를 쓴다. → ③ 정답은 ①.
문장별 판정:
정답 판단: last Monday에는 과거형(ran into), since last winter에는 현재완료(haven't talked to)를 쓰므로 정답은 ①이다.
선택지 분석:
① [정답] last Monday에는 과거형(ran into), since last winter에는 현재완료(haven't talked to)를 쓰므로 정답이다.
② [오답] 지금까지 이어지는 기간(since last winter)에는 didn't talk to가 아니라 현재완료를 써야 하므로 오답이다.
③ [오답] 지금까지 이어지는 기간(since last winter)에는 don't talk to가 아니라 현재완료를 써야 하므로 오답이다.
④ [오답] 끝난 과거 시점(last Monday)과 현재완료(have run into)를 함께 쓸 수 없으므로 오답이다.
⑤ [오답] 두 빈칸 모두 시제가 맞지 않으므로 오답이다.
```
