## 원본 해설

```
핵심 규칙: 일반동사 현재형의 의문문은 ‘Do/Does + 주어 + 동사원형 ~?’이다. 복수 주어와 I, you에는 Do, 3인칭 단수 주어에는 Does를 쓴다.
풀이 순서: ① 동사(play)가 일반동사의 현재형이다. 의문문은 Do/Does + 주어 + 동사원형이다. → ② 주어(They, 복수)에 맞춰 Do를 쓴다. 본동사는 원형으로 쓴다. → ③ 정답은 ①.
문장별 판정:
정답 판단: Do + 주어 + 동사원형으로 바르게 바꿨으므로 정답은 ①이다.
선택지 분석:
① [정답] Do + 주어 + 동사원형으로 바르게 바꿨으므로 정답이다.
② [오답] 복수 주어 they에 Does를 쓸 수 없으므로 오답이다.
③ [오답] 일반동사 의문문에 be동사를 쓰지 않고 plays도 틀렸으므로 오답이다.
④ [오답] 현재 문장을 과거로 바꿨고 Did 뒤에 played도 쓸 수 없으므로 오답이다.
⑤ [오답] Do 뒤에는 동사원형 play를 써야 하므로 오답이다.
```
