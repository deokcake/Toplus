# 3-2 D 유형 — 시제와 수에 맞는 There + be동사

- 급·챕터·번호: 3급 · CH 1 be동사 · 2번 · D 유형
- 정답: ①
- 총 길이: 135초
- 화면: 칠판에 분필로 판서하듯 ‘판서 순서’대로 한 줄씩 써 나간다. 강조 = 노란 분필, 지움 = 분필 줄 긋기.

| 3. 핵심 규칙 | 31초 | 핵심 규칙<br>There + be동사 + 명사 = ‘~이 있다’, ‘~이 있었다’<br>There 뒤 be동사는 뒤에 오는 명사의 수에 맞춰요: 단수 → is, was / 복수 → are, were<br>시제에도 맞춰요: 현재 → is, are / 과거 → was, were<br>셀 수 없는 명사(milk, money)는 단수로 취급해요<br>예) There are three pens in my bag. (내 가방에 펜이 세 자루 있어요.) | There 뒤에 be동사와 명사를 쓰면 어디에 무엇이 있다, 또는 있었다는 뜻이에요. 이때 be동사는 뒤에 오는 명사가 단수이면 is나 was, 복수이면 are나 were를 쓰고, milk처럼 셀 수 없는 명사는 단수로 취급해요. 또 현재이면 is나 are, 과거이면 was나 were를 써요. 예를 들어 There are three pens in my bag. 내 가방에 펜이 세 자루 있어요. | 시제와 뒤 명사의 수에 맞춰요 |
| 4. 풀이 순서 | 34초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** Now = 지금 → 현재. 과거형 were, was가 든 ②③을 지운다. / 강조 `Now,` / 지움 `② There were`, `③ There was`<br>**2단계** two books = 두 권 → 복수. 단수 명사 앞의 There is, 주어 I에만 쓰는 am을 지운다. / 강조 `two books` / 지움 `⑤ There is`, `④ There am`<br>**3단계** 현재 + 복수 → There are / 강조 `① There are` | 첫째, Now는 지금이라는 뜻이라 현재이므로, 과거형인 2번 There were와 3번 There was를 지워요. 둘째, 뒤에 오는 명사 two books는 책 두 권이라 복수예요. 그래서 단수일 때 쓰는 5번 There is를 지우고, 주어 I에만 쓰는 am이 들어간 4번 There am도 지워요. 셋째, 남는 것은 1번 There are예요. Now, there are two books on the table. 지금 탁자 위에 책이 두 권 있어요. | 현재 → 복수 → There are |
| 5. 선택지 확인 | 28초 | ① There are  ✓  현재 + 복수 two books<br>② There were  ✗  복수는 맞지만 were는 과거형이에요 (Now)<br>③ There was  ✗  was는 과거형이고 단수 명사 앞에 써요<br>④ There am  ✗  am은 주어 I에만 써요<br>⑤ There is  ✗  현재는 맞지만 is는 단수 명사 앞에 써요 (two books) | 정답은 1번 There are예요. 5번 There is는 현재형이라 고르기 쉽지만, 뒤의 명사가 단수일 때 쓰는 꼴이라 복수 two books와 맞지 않아요. 2번 There were는 복수 명사 앞에 쓰지만, 과거형이라 Now와 맞지 않아요. 3번 There was는 과거형인 데다 단수 명사 앞에 써서 두 가지가 다 틀렸어요. | 정답 ① There are |
| 6. 정리 | 13초 | 정답 ① There are<br><br>There + be동사는 시제와 뒤 명사의 수에 맞춰요: 현재 + 복수 → There are | 정답은 1번이에요. 기억할 것, There 뒤의 be동사는 시제와 뒤에 오는 명사의 수에 맞춰요. 현재이고 복수이면 There are를 써요. | 현재·복수 → There are |

## 원본 해설

```
핵심 규칙: there 구문은 뒤의 실제 명사구의 수와 문장의 시제에 맞춰 there is/are/was/were를 선택한다.
풀이 순서: ① 문장 앞의 시간 표현으로 시제를 정한다(Now → 현재). → ② There 뒤 be동사는 뒤에 오는 명사에 수를 맞춘다(two books, 복수). → ③ 정답은 There are.
문장별 판정:
정답 판단: Now는 현재를 나타내고 two books는 복수이므로 There are가 맞다. 따라서 정답은 ①이다.
선택지 분석:
① [정답] Now는 현재를 나타내고 two books는 복수이므로 There are가 맞다.
② [오답] were는 과거형이므로 현재를 나타내는 Now와 맞지 않는다.
③ [오답] was는 과거형이므로 현재를 나타내는 Now와 맞지 않는다. was는 단수형이므로 복수 명사구 two books와 수가 맞지 않는다.
④ [오답] am은 주어 I에 쓰는 형태로, 이 there 구문의 명사구와 결합하지 않는다.
⑤ [오답] is는 단수형이므로 복수 명사구 two books와 수가 맞지 않는다.
```
