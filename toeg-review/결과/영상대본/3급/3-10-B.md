| 3. 핵심 규칙 | 31초 | 핵심 규칙<br>be동사 과거형: 주어가 I, 3인칭 단수(he, she, it, 단수 명사) → was<br>주어가 you, 복수(we, they, 복수 명사) → were<br>There was, There were (…이 있었다) → 뒤에 오는 명사에 맞춰요<br>a lot of + 복수 명사 → were · a lot of + 셀 수 없는 명사 → was<br>예) There were a lot of birds in the park. | 4. 풀이 순서 | 35초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** There 문장: be동사 뒤 a lot of people(복수) → there were (was ✗) / 강조 `a lot of people` / 지움 `there was a lot of people`<br>**2단계** 나머지는 주어: The bus = 한 대 → was (were ✗) · My friends and I = 여러 명 → were ✓ · The driver = 한 명 → was ✓ / 강조 `My friends and I were`, `The driver was` / 지움 `The bus were`<br>**3단계** 틀린 문장: 첫째, 둘째 → 2개 / 강조 `② 2개` / 지움 `① 1개`, `③ 3개`, `④ 4개`, `⑤ 없음` | 첫째, 첫 번째 문장처럼 there 뒤에 be동사가 오면 be동사 뒤의 명사 a lot of people에 맞춰요. people은 복수 명사라서 there were를 써야 하니 틀렸어요. 둘째, 나머지 문장은 주어를 봐요. | 5. 선택지 확인 | 27초 | ① 1개  ✗  첫째도 틀려요: a lot of people은 복수 → there were<br>② 2개  ✓  틀린 문장은 첫째, 둘째 두 개<br>③ 3개  ✗  셋째 My friends and I는 여러 명 → were가 맞아요<br>④ 4개  ✗  넷째 The driver was도 옳아요<br>⑤ 없음  ✗  둘째 The bus were부터 틀려요 (버스 한 대 → was) | 정답은 2번, 2개예요. 첫 번째 문장은 a lot of의 a를 보고 was가 맞다고 생각하기 쉬운데, 이 문장을 놓치면 1번을 고르게 돼요. 세 번째 문장은 주어 끝의 I만 보고 was를 떠올리기 쉽지만, My friends and I는 여러 명이라 were가 맞아요. 이 문장까지 틀렸다고 세면 3번을 고르게 돼요. | 정답 ② 2개 |

## 원본 해설

```
핵심 규칙: there 구문은 뒤의 실제 명사의 수와 문장의 시제에 맞춰 there is/are/was/were를 고른다. 주어가 있는 문장은 주어의 수·시제에 맞춰 was/were를 쓴다(a lot of + 셀 수 없는 명사는 단수, 복수명사는 복수).
풀이 순서: ① 문장마다 주어를 찾는다. there was/were는 뒤의 명사가 주어다. → ② 단수 주어(셀 수 없는 명사 포함)에는 was, 복수 주어에는 were인지 확인한다. → ③ 첫째는 a lot of people이 복수라 were, 둘째는 The bus가 단수라 was여야 한다. 틀린 문장은 2개이다.
문장별 판정:
첫째 X. 뒤의 명사(a lot of people)가 복수이므로 there were이다.
둘째 X. 단수 주어(The bus)의 과거는 was이다.
셋째 O. 복수 주어(My friends and I)의 과거는 were이다.
넷째 O. 단수 주어(the driver)의 과거는 was이다.
정답 판단: 어법상 틀린 문장은 첫째, 둘째로 2개이다.
선택지 분석:
① [오답] 어법상 틀린 문장은 첫째, 둘째로 2개이다. 이 보기의 1개는 실제 개수와 일치하지 않는다.
② [정답] 어법상 틀린 문장은 첫째, 둘째로 2개이다. 이 보기의 2개는 실제 개수와 일치한다.
③ [오답] 어법상 틀린 문장은 첫째, 둘째로 2개이다. 이 보기의 3개는 실제 개수와 일치하지 않는다.
④ [오답] 어법상 틀린 문장은 첫째, 둘째로 2개이다. 이 보기의 4개는 실제 개수와 일치하지 않는다.
⑤ [오답] 어법상 틀린 문장은 첫째, 둘째로 2개이다. 이 보기의 없음은 실제 개수와 일치하지 않는다.
```
