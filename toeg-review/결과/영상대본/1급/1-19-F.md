# 1-19 F 유형 — 과거형과 과거완료 had + 과거분사

- 급·챕터·번호: 1급 · CH 2 시제 · 19번 · F 유형

| 3. 핵심 규칙 | 32초 | 핵심 규칙<br>had + 과거분사(과거완료): 과거의 어느 때보다 먼저 일어난 일<br>기준이 되는 과거의 한 순간 → 과거형<br>has / have + 과거분사(현재완료)는 지금이 기준 → 과거가 기준이면 쓰지 않아요<br>예) When I called Jina, she had already gone to bed. (내가 지나에게 전화했을 때, 지나는 이미 잠자리에 든 뒤였어요.) | 과거완료는 had 뒤에 과거분사를 써서, 과거의 어느 때보다 먼저 일어난 일을 나타내요. 현재완료 has나 have는 지금이 기준이라, 기준이 과거이면 쓰지 않아요. 예를 들어 When I called Jina, she had already gone to bed. 내가 지나에게 전화했을 때, 지나는 이미 잠자리에 든 뒤였어요. 기준인 전화한 순간은 과거형 called, 그보다 먼저 잠든 일은 had gone이에요. | 먼저 일어난 일은 had + 과거분사 |
| 4. 풀이 순서 | 32초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** (A) ‘도착했을 때’ = 기준이 되는 과거의 한 순간 → 과거형 reached. 기준을 과거완료로 쓴 had reached ⑤ 지움 / 강조 `When I`, `도착했을 때` / 지움 `⑤ had reached - had - closed`<br>**2단계** (B) ‘이미 문을 닫은 뒤였다’ = 도착보다 먼저 일어난 일 → 과거완료 had. 현재완료 has ①② 지움 / 강조 `already`, `이미 그날 문을 닫은 뒤였다` / 지움 `① reached - has - close`, `② reached - has - closed`<br>**3단계** (C) 과거완료 had 뒤 → 과거분사 closed. 동사원형 close ④ 지움 → ③ / 강조 `③ reached - had - closed` / 지움 `④ reached - had - close` | 첫째, 에이 빈칸은 우리말로 도착했을 때예요. 기준이 되는 과거의 한 순간이라 과거형 reached를 쓰니, 과거완료 had reached인 5번을 지워요. 둘째, 빵집이 이미 문을 닫은 일은 도착보다 먼저라 비 빈칸은 과거완료의 had이니, 현재완료 has인 1번과 2번을 지워요. 셋째, 과거완료 had 뒤의 씨 빈칸은 과거분사 closed라, 동사원형 close인 4번을 지우면 3번이 남아요. | reached → had → closed |
| 5. 선택지 확인 | 24초 | ① reached - has - close  ✗  현재완료 has, 동사원형 close까지 두 곳이 틀림<br>② reached - has - closed  ✗  기준이 과거라 현재완료 has는 쓸 수 없어요<br>③ reached - had - closed  ✓  도착은 과거형, 먼저 문을 닫은 일은 had closed<br>④ reached - had - close  ✗  과거완료는 had + 과거분사(closed)<br>⑤ had reached - had - closed  ✗  기준이 되는 도착은 과거형 reached로 | 정답은 3번이에요. 도착은 과거형 reached로, 그보다 먼저 문을 닫은 일은 had closed로 썼어요. 2번은 already가 있어서 has를 고르기 쉽지만, 기준이 과거라 현재완료는 쓸 수 없어요. 5번은 먼저 일어난 일이 아니라 기준인 도착을 had reached로 써서 틀렸어요. | 정답 ③ reached - had - closed |
| 6. 정리 | 11초 | 정답 ③ reached - had - closed<br><br>기준이 되는 과거의 순간 → 과거형, 그보다 먼저 일어난 일 → had + 과거분사 | 정답은 3번이에요. 기억할 것, 기준이 되는 과거의 순간은 과거형, 그보다 먼저 일어난 일은 had와 과거분사예요. | 먼저 일어난 일 → had + 과거분사 |

## 원본 해설

```
핵심 규칙: 과거의 기준 사건에는 단순과거를, 그보다 먼저 끝난 사건에는 had + 과거분사를 쓴다.
풀이 순서: ① when절의 우리말(‘도착했을 때’)이 과거이므로 (A)는 과거형이다. → ② 주절의 already와 우리말 ‘이미 문을 닫은 뒤였다’로 보아 그보다 먼저 끝난 일이므로 (B)(C)는 had + 과거분사다. → ③ (A)를 다른 시제로 쓴 보기와 has·was·동사원형이 들어간 보기를 지운다. 정답은 reached - had - closed.
문장별 판정:
정답 판단: 도착한 일이 기준이고 빵집이 문을 닫은 일은 그보다 먼저이므로 reached - had - closed가 알맞다.
선택지 분석:
① [오답] (B) has: 현재완료의 has이어서 맞지 않는다. (B)는 그보다 먼저 끝난 일을 나타내는 과거완료의 had가 와야 한다. (C) close: 동사원형이어서 맞지 않는다. (C)는 had 뒤이므로 과거분사가 와야 한다. 따라서 오답이다.
② [오답] (B) has: 현재완료의 has이어서 맞지 않는다. (B)는 그보다 먼저 끝난 일을 나타내는 과거완료의 had가 와야 한다. 따라서 오답이다.
③ [정답] 도착한 일이 기준이고 빵집이 문을 닫은 일은 그보다 먼저이므로 reached - had - closed가 알맞다. 모든 자리가 알맞으므로 정답이다.
④ [오답] (C) close: 동사원형이어서 맞지 않는다. (C)는 had 뒤이므로 과거분사가 와야 한다. 따라서 오답이다.
⑤ [오답] (A) had reached: 과거완료이어서 맞지 않는다. (A)는 기준이 되는 과거 사건이므로 단순과거를 쓴다. 따라서 오답이다.
```
