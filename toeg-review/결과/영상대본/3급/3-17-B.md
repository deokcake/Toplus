## 원본 해설

```
핵심 규칙: 현재 일반동사 의문문은 Do/Does + 주어 + 동사원형으로 만든다. 3인칭 단수 주어에는 Does를 쓰고, be동사나 did·과거형을 섞지 않는다.
풀이 순서: ① 동사(drink)가 일반동사의 현재형이다. 의문문은 Do/Does + 주어 + 동사원형이다. → ② 주어(My parents, 복수)에 맞춰 Do를 쓴다. 본동사는 원형으로 쓴다. → ③ 정답은 ⑤.
문장별 판정:
정답 판단: Do/Does + 주어 + 동사원형으로 바르게 바꿨으므로 정답은 ⑤이다.
선택지 분석:
① [오답] 복수 주어(my parents)에는 Do를 쓰므로 오답이다.
② [오답] 일반동사 문장에는 be동사로 의문문을 만들지 않으므로 오답이다.
③ [오답] Do 뒤에는 동사원형(drink)을 쓰므로 오답이다.
④ [오답] 현재 문장을 과거로 바꿨고, Did 뒤에도 동사원형을 쓰므로 오답이다.
⑤ [정답] Do/Does + 주어 + 동사원형으로 바르게 바꿨으므로 정답이다.
```
