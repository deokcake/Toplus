## 원본 해설

```
핵심 규칙: 과거에 시작한 동작이 현재도 계속되고 있음을 명시할 때 have/has been + 동사-ing을 쓰며, 시작 시점에는 since, 기간에는 for를 쓴다.
풀이 순서: ① 첫 문장에서 시작한 때(at 2 p.m.)를, 둘째 문장에서 지금도 계속됨(still ~ now)을 확인한다. → ② 과거에 시작해 지금까지 이어지는 동작이므로 have/has been + -ing를 쓴다. 지금까지 이어진다는 뜻이 없는 시제를 지운다. → ③ 2시는 시작 시점이므로 at이 아니라 since 2 p.m.으로 쓴다. 정답은 ③.
문장별 판정:
정답 판단: ‘We have been discussing the issue since 2 p.m.’가 have/has been + -ing과 올바른 since/for를 사용하여 현재까지의 계속을 나타내므로 정답이다.
선택지 분석:
① [오답] ‘We have discussing the issue since 2 p.m.’은 현재완료진행에서 have/has been + -ing이므로 been이 빠졌다. 따라서 오답이다.
② [오답] ‘We were discussing the issue since 2 p.m.’은 과거진행으로, 특정 과거 시점의 진행을 나타내며 현재까지 계속된다는 의미를 만들지 못한다. 따라서 오답이다.
③ [정답] ‘We have been discussing the issue since 2 p.m.’은 have/has been + -ing 구조를 쓰고 시작 시점/기간 표현도 맞아 과거부터 지금까지 계속되는 동작을 정확히 나타낸다. 따라서 정답이다.
④ [오답] ‘We had been discussing the issue since 2 p.m.’은 과거완료진행으로, 다른 과거 시점까지의 계속을 나타내므로 현재까지의 계속과 맞지 않는다. 따라서 오답이다.
⑤ [오답] ‘We have been discussing the issue at 2 p.m.’은 시작 시점을 이어 주려면 at이 아니라 since가 필요하다. 따라서 오답이다.
```
