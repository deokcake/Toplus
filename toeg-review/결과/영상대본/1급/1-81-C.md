# 1-81 C 유형 — 선행사 a place 뒤 관계부사와 관계대명사

- 급·챕터·번호: 1급 · CH 9 관계사 · 81번 · C 유형
- 정답: ④
- 총 길이: 142초
- 화면: 칠판에 분필로 판서하듯 ‘판서 순서’대로 한 줄씩 써 나간다. 강조 = 노란 분필, 지움 = 분필 줄 긋기.

| 2. 문제 | 20초 | 다음 빈칸에 들어갈 말로 가장 알맞은 것을 고르시오.<br><br>The research center is a place _____ scientists test new materials.<br><br>① which<br>② why<br>③ whom<br>④ where<br>⑤ when | 다음 빈칸에 들어갈 말로 가장 알맞은 것을 고르시오. | 3. 핵심 규칙 | 29초 | 핵심 규칙<br>선행사 + 관계부사 + 완전한 절 (주어·목적어가 빠지지 않은 절)<br>장소(place) → where, 때(day, season) → when, 이유(reason) → why<br>관계대명사 which는 뒤 절의 주어·목적어 자리, whom은 목적어 자리를 맡아요<br>예) This is the house where I was born. (이곳은 내가 태어난 집이에요.) | 관계부사는 선행사를 꾸미는 절을 이끌고, 선행사가 장소면 where, 때면 when, 이유면 why를 써요. 관계부사 뒤에는 주어나 목적어가 빠지지 않은 완전한 절이 와요. 반면 관계대명사 which는 뒤 절의 주어나 목적어 자리를, whom은 목적어 자리를 맡아요. 예를 들어 This is the house where I was born. 이곳은 내가 태어난 집이에요. | 장소 where, 때 when, 이유 why |
| 4. 풀이 순서 | 38초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** 선행사 a place = 장소 / 강조 `a place`<br>**2단계** scientists(주어) + test(동사) + new materials(목적어) = 완전한 절 → 관계대명사 which, whom 지움 / 강조 `scientists test new materials` / 지움 `① which`, `③ whom`<br>**3단계** 남은 관계부사 why, where, when 중 장소 선행사에 맞는 것 → where (이유의 why, 때의 when 지움) / 강조 `④ where` / 지움 `② why`, `⑤ when` | 첫째, 빈칸 앞의 선행사 a place는 장소를 나타내요. 둘째, 빈칸 뒤를 보면 scientists가 주어, test가 동사, new materials가 목적어예요. 빠진 성분이 없는 완전한 절이니 관계대명사 which와 whom은 들어갈 수 없어요. 셋째, 남은 관계부사 why, where, when 가운데 장소를 나타내는 선행사에 맞는 것은 where예요. The research center is a place where scientists test new materials. 그 연구소는 과학자들이 새로운 재료를 시험하는 곳이에요. | 장소 → 완전한 절 → where |
| 5. 선택지 확인 | 32초 | ① which  ✗  scientists test new materials에 주어·목적어 빈자리가 없어요 (in which = where)<br>② why  ✗  이유를 나타내는 선행사(the reason) 뒤에 써요<br>③ whom  ✗  사람 선행사 뒤 목적어 자리, a place는 사람이 아님<br>④ where  ✓  장소 선행사 a place + 완전한 절<br>⑤ when  ✗  때를 나타내는 선행사(the day, the season) 뒤에 써요 | 정답은 4번 where예요. 1번 which는 사물 선행사 뒤에 쓰니 맞아 보이지만, 관계대명사라 뒤 절의 주어나 목적어 자리를 맡아야 해요. scientists test new materials는 목적어까지 갖춰서 빈자리가 없어요. which를 쓰려면 in which처럼 전치사를 붙여야 where와 같은 뜻이 돼요. 5번 when은 the day처럼 때를 나타내는 선행사 뒤에 써요. | 정답 ④ where |
| 6. 정리 | 13초 | 정답 ④ where<br><br>관계부사 뒤에는 완전한 절: 장소 → where, 때 → when, 이유 → why | 정답은 4번이에요. 기억할 것, 관계부사는 선행사가 장소면 where, 때면 when, 이유면 why를 쓰고, 그 뒤에는 완전한 절이 와요. | 관계부사 뒤에는 완전한 절 |

## 원본 해설

```
핵심 규칙: 장소 관계부사 where는 선행사와 뒤의 완전한 절 사이에서 부사어 관계를 나타낸다. 뒤 절의 필수 성분이 갖추어졌는지 함께 확인한다.
풀이 순서: ① 빈칸 앞의 선행사(a place)가 무엇을 나타내는지 본다. → ② 빈칸 뒤의 절(scientists test new materials)에 주어·목적어 등 빠진 성분이 없으므로 관계대명사(which, whom)가 아니라 관계부사 자리다. → ③ 선행사가 장소이므로 where를 쓴다. 정답은 where.
문장별 판정:
정답 판단: scientists가 주어, test가 동사, new materials가 목적어이다. 선행사의 장소 관계를 잇는 where가 맞다.
선택지 분석:
① [오답] 관계대명사 which가 절 안에서 맡을 주어·목적어 자리가 없으므로 이 형태로는 맞지 않는다. 적절한 전치사와 which를 함께 쓰는 구조와 구별한다.
② [오답] why는 이 문항의 장소 선행사 관계를 나타내지 못한다. where로 고친다.
③ [오답] whom은 사람을 가리키는 관계대명사로 이 선행사와 맞지 않으며, 뒤의 절에도 그에 해당하는 주어·목적어 빈자리가 없다.
④ [정답] scientists가 주어, test가 동사, new materials가 목적어이다. 선행사의 장소 관계를 잇는 where가 맞다.
⑤ [오답] when은 이 문항의 장소 선행사 관계를 나타내지 못한다. where로 고친다.
```
