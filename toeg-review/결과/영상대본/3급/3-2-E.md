# 3-2 E 유형 — 시제와 수에 맞는 There + be동사

## 원본 해설

```
핵심 규칙: 현재 존재문에서 셀 수 없는 명사 water는 단수 취급하므로 there is를 쓴다.
풀이 순서: ① 문장 앞의 시간 표현으로 시제를 정한다(Right now → 현재). → ② There 뒤 be동사는 뒤에 오는 명사에 수를 맞춘다(a lot of water, 셀 수 없는 명사라 단수). → ③ 정답은 There is.
문장별 판정:
정답 판단: water를 단수 취급하고 현재를 나타내므로 There is가 맞다. 따라서 정답은 ⑤이다.
선택지 분석:
① [오답] was는 과거형이므로 Right now(지금)와 시제가 맞지 않는다. There is로 고른다.
② [오답] water는 불가산명사이므로 복수형 are를 쓸 수 없다. There is가 필요하다.
③ [오답] am은 주어 I에 쓰는 현재형이다. 이 존재문에는 There is가 필요하다.
④ [오답] were는 과거·복수형이므로 현재의 water와 맞지 않는다. There is가 필요하다.
⑤ [정답] water를 단수 취급하고 현재를 나타내므로 There is가 맞다.
```
