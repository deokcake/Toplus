풀이 순서: ① (A)는 의문문 맨 앞의 be동사다. 주어에 맞춘다(she → Is). → ② (B)는 No 뒤의 짧은 대답이다. 질문의 주어를 대명사로 받아 ‘주어 + be동사’를 쓴다(she's). 뒤에 not이 있으므로 be동사가 꼭 들어가야 한다. → ③ 정답은 ③.
