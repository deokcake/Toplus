# 2-2 — 5형식과 3형식 구별하기

- 급·챕터·번호: 2급 · CH 1 문장의 형식 · 2번
- 정답: ⑤
- 총 길이: 122초
- 화면: 칠판에 분필로 판서하듯 ‘판서 순서’대로 한 줄씩 써 나간다. 강조 = 노란 분필, 지움 = 분필 줄 긋기.

| 장면 | 길이 | 화면(판서 순서) | 내레이션 | 자막 |
|---|---|---|---|---|
| 1. 도입 | 10초 | 2급 · CH 1 문장의 형식 · 2번<br><br>이 문제는 목적격 보어가 있는지 따져 5형식이 아닌 문장을 고르는 문제예요. | 2급 챕터 1, 2번. 이 문제는 목적격 보어가 있는지 따져 5형식이 아닌 문장을 고르는 문제예요. | 5형식이 아닌 문장 찾기 |
| 2. 문제 | 14초 | 다음 중 5형식 문장이 아닌 것을 고르시오.<br><br>① They elected him president.<br>② We consider her honest.<br>③ The noise drove me crazy.<br>④ She painted the wall blue.<br>⑤ I want some pizza. | 다음 중 5형식 문장이 아닌 것을 고르시오. 먼저 풀어 보세요. 영상을 잠시 멈춰도 좋아요. | 먼저 풀어 보세요 |
| 3. 핵심 규칙 | 30초 | 핵심 규칙<br>5형식 = 주어 + 동사 + 목적어 + 목적격 보어<br>목적격 보어(명사, 형용사, to부정사, 분사 등) → 목적어의 이름·신분·상태·행동을 설명<br>동사 뒤에 목적어 하나만 있고 그것을 설명하는 말이 없으면 → 3형식<br>예) The song makes me happy. (그 노래는 나를 행복하게 해요. happy → me의 상태) | 5형식 문장은 주어, 동사, 목적어 뒤에 목적격 보어가 오는 문장이에요. 목적격 보어는 명사, 형용사, to부정사, 분사 같은 말로, 목적어의 이름이나 신분, 상태, 행동을 설명해요. 예를 들어 The song makes me happy. 그 노래는 나를 행복하게 해요. 반면 동사 뒤에 목적어 하나만 있고 그것을 설명하는 말이 없으면 3형식이에요. | 목적어 + 목적격 보어 = 5형식 |
| 4. 풀이 순서 | 32초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** 5형식이 ‘아닌’ 것 → 문장마다 동사 뒤에 ‘목적어 + 목적어를 설명하는 말’이 있는지 본다. / 강조 `5형식 문장이 아닌 것`<br>**2단계** president = him의 신분 / honest, crazy, blue = her, me, the wall의 상태 → ①~④ 모두 5형식 / 강조 `him president`, `her honest`, `me crazy`, `the wall blue` / 지움 `① They elected him president.`, `② We consider her honest.`, `③ The noise drove me crazy.`, `④ She painted the wall blue.`<br>**3단계** want 뒤에는 목적어 some pizza 하나뿐, 설명하는 말 없음 → 3형식 / 강조 `want some pizza` | 첫째, 문장마다 동사 뒤에 목적어와 그 목적어를 설명하는 말이 함께 있는지 봐요. 둘째, 1번 president는 him의 신분을, 2번 honest, 3번 crazy, 4번 blue는 her, me, the wall의 상태를 나타내요. 그래서 1번부터 4번까지는 모두 5형식이에요. 셋째, 5번은 want 뒤에 목적어 some pizza만 있고 그것을 설명하는 말이 없으니 3형식이에요. | 보어 확인 → 목적어만 → ⑤ |
| 5. 선택지 확인 | 26초 | ① They elected him president.  ✗  president가 him의 신분(him = president) → 5형식<br>② We consider her honest.  ✗  honest가 her의 성질을 설명 → 5형식<br>③ The noise drove me crazy.  ✗  crazy가 me의 상태를 설명 → 5형식<br>④ She painted the wall blue.  ✗  blue가 칠한 뒤 the wall의 색깔을 설명 → 5형식<br>⑤ I want some pizza.  ✓  want 뒤에 목적어 some pizza만 → 3형식 | 정답은 5번 I want some pizza, 나는 피자를 좀 원한다는 문장이에요. 4번은 벽을 칠했다는 3형식처럼 보이지만, blue가 칠한 뒤 벽의 색깔을 설명하니 5형식이에요. 3번 drove me crazy는 나를 미치게 만들었다는 뜻이고, crazy가 me의 상태를 설명하는 5형식이에요. | 정답 ⑤ (3형식) |
| 6. 정리 | 10초 | 정답 ⑤ I want some pizza.<br><br>목적어 + 목적격 보어 → 5형식, 목적어 하나만 → 3형식 | 정답은 5번이에요. 기억할 것, 목적어 뒤에 그 목적어를 설명하는 목적격 보어가 있어야 5형식이에요. | 목적어 + 목적격 보어 → 5형식 |

## 원본 해설

```
핵심 규칙: 5형식은 ‘주어 + 동사 + 목적어 + 목적격 보어’다. 목적격 보어(명사, 형용사, to부정사, 분사 등)는 목적어의 이름·상태·행동을 설명한다.
풀이 순서: ① 문장마다 동사 뒤에 ‘목적어 + 목적어를 설명하는 말’이 이어지는지 본다. → ② 목적어 뒤의 말이 목적어의 이름·상태·행동을 나타내면 5형식이다. → ③ 선택지 ⑤는 want 뒤에 목적어 some pizza만 있는 3형식이다. 5형식이 아니다.
문장별 판정:
정답 판단: want 뒤에 목적어(some pizza)만 있는 3형식이므로 정답은 ⑤이다.
선택지 분석:
① [오답] him = president 관계의 5형식이므로 오답이다.
② [오답] her의 성질을 honest가 설명하는 5형식이므로 오답이다.
③ [오답] me의 상태를 crazy가 설명하는 5형식이므로 오답이다.
④ [오답] the wall의 상태를 blue가 설명하는 5형식이므로 오답이다.
⑤ [정답] want 뒤에 목적어(some pizza)만 있는 3형식이므로 정답이다.
```
