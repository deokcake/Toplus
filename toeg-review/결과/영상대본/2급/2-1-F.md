# 2-1 F 유형 — stayed quiet와 같은 2형식

- 급·챕터·번호: 2급 · CH 1 문장의 형식 · 1번 · F 유형
- 정답: ①
- 총 길이: 120초

| 2. 문제 | 19초 | 다음 주어진 문장의 형식과 같은 것을 고르시오.<br><br>The room stayed quiet.<br><br>① The audience remained silent.<br>② She kept the door open.<br>③ The bus left early.<br>④ The storm damaged the roof.<br>⑤ I lent him some money. | 다음 주어진 문장의 형식과 같은 것을 고르시오. | 3. 핵심 규칙 | 27초 | 핵심 규칙<br>2형식 = 주어 + 동사 + 주격 보어<br>주격 보어: 주어의 상태나 성질을 설명하는 말<br>become, turn, grow, seem, look, sound, smell, stay, remain 뒤에서 주어를 설명하는 형용사 = 주격 보어<br>동사 뒤에 목적어 → 3·4·5형식 / 부사(구)만 → 1형식<br>예) She stayed calm. (그녀는 침착함을 유지했어요.) | 2형식은 주어, 동사, 그리고 주어를 설명하는 주격 보어로 된 문장이에요. stay, remain, look 같은 동사 뒤에 형용사가 와서 주어의 상태를 설명하면 2형식이에요. She stayed calm. 그녀는 침착함을 유지했어요. 동사 뒤에 목적어가 오면 3, 4, 5형식이고, 부사나 부사구만 오면 1형식이에요. | 2형식 = 주어 + 동사 + 주격 보어 |
| 4. 풀이 순서 | 30초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** 주어진 문장: stayed 뒤 형용사 quiet가 주어 The room을 설명 → 2형식 / 강조 `stayed quiet`<br>**2단계** ②④⑤ 동사 뒤 목적어(5·3·4형식), ③ early = ‘일찍’, left를 꾸미는 부사(1형식) → 지움 / 강조 `the door open`, `left early`, `the roof`, `him some money` / 지움 `② She kept the door open.`, `③ The bus left early.`, `④ The storm damaged the roof.`, `⑤ I lent him some money.`<br>**3단계** 남는 것은 ① remained 뒤 형용사 silent가 주어를 설명 → 2형식 / 강조 `remained silent` | 첫째, 주어진 문장에서 stayed 뒤의 형용사 quiet가 주어 The room을 설명하니까 2형식이에요. 둘째, 2번, 4번, 5번은 동사 뒤에 목적어가 있고, 3번의 early는 left를 꾸미는 부사라서 2형식이 아니에요. 셋째, 남은 1번은 remained 뒤의 형용사 silent가 주어를 설명하는 2형식이에요. The audience remained silent. 관객들은 계속 침묵했어요. | 목적어·부사 걸러 내기 → remained silent |
| 5. 선택지 확인 | 25초 | ① The audience remained silent.  ✓  remained 뒤 형용사 silent가 주어를 설명 → 2형식<br>② She kept the door open.  ✗  open은 목적어 the door를 설명 → 5형식<br>③ The bus left early.  ✗  early는 left를 꾸미는 부사(일찍) → 1형식<br>④ The storm damaged the roof.  ✗  damaged 뒤에 목적어 the roof → 3형식<br>⑤ I lent him some money.  ✗  목적어 두 개(him, some money) → 4형식 | 정답은 1번이에요. 2번의 open은 주어가 아니라 목적어 the door를 설명하는 목적격 보어라서 5형식이에요. She kept the door open. 그녀는 문을 열어 두었어요. 3번 The bus left early는 버스가 일찍 떠났다는 뜻이에요. 여기서 early는 left를 꾸미는 부사라서 1형식이에요. | 정답 ① remained silent |
| 6. 정리 | 10초 | 정답 ① The audience remained silent.<br><br>동사 뒤의 형용사가 주어를 설명하면 → 2형식 (주어 + 동사 + 주격 보어) | 정답은 1번이에요. 기억할 것, stay, remain 같은 동사 뒤의 형용사가 주어를 설명하면 2형식이에요. | 형용사가 주어 설명 → 2형식 |

## 원본 해설

```
핵심 규칙: 제시문과 각 선택지를 명사구 단위로 S·V·O·C로 나누어 1~5형식을 판정한다. 연결동사 뒤의 형용사는 주격보어이며, 장소·시간·방법 표현은 보통 부사어이다.
풀이 순서: ① 주어진 문장의 동사(stayed) 뒤에 오는 형용사(quiet)가 주어의 상태를 설명한다. 2형식이다. → ② 보기에서 동사 뒤의 말을 본다. 목적어(명사)가 오면 3·4·5형식이고, 부사(구)만 오면 1형식이다. → ③ 선택지 ①만 ‘동사 + 형용사 보어’(remained silent) 구조다.
문장별 판정:
정답 판단: ‘The audience remained silent’는 The audience(S) + remained(V) + silent(C)의 2형식이다. 연결동사 뒤의 보어가 주어의 상태·성질을 설명한다. 제시문의 형식은 2형식이다. 정답 선택지만 제시문과 같은 2형식이므로 정답이다.
선택지 분석:
① [정답] ‘The audience remained silent’는 The audience(S) + remained(V) + silent(C)의 2형식이다. 연결동사 뒤의 보어가 주어의 상태·성질을 설명한다. 제시문의 형식은 2형식이다. 같은 형식이므로 정답이다.
② [오답] ‘She kept the door open’은 She(S) + kept(V) + the door(O) + open(OC)의 5형식이다. 목적격보어가 목적어의 상태·신분·행동을 설명한다. 제시문의 형식은 2형식이다. 제시문과 형식이 다르므로 오답이다.
③ [오답] ‘The bus left early’는 The bus(S) + left(V) + 부사어의 1형식이다. 뒤의 표현이 있다면 부사어로 핵심 형식에 포함되지 않는다. 제시문의 형식은 2형식이다. 제시문과 형식이 다르므로 오답이다.
④ [오답] ‘The storm damaged the roof’는 The storm(S) + damaged(V) + the roof(O)의 3형식이다. 동사 뒤의 명사구가 목적어이다. 제시문의 형식은 2형식이다. 제시문과 형식이 다르므로 오답이다.
⑤ [오답] ‘I lent him some money’는 I(S) + lent(V) + him(IO) + some money(DO)의 4형식이다. 간접목적어와 직접목적어가 차례로 온다. 제시문의 형식은 2형식이다. 제시문과 형식이 다르므로 오답이다.
```
