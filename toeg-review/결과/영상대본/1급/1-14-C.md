| 4. 풀이 순서 | 34초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** 우리말의 순서: 끝낸 일(먼저) → 알게 된 일(나중, 기준) / 강조 `보고서를 이미 끝내 놓았다`, `것을 알았다`<br>**2단계** 첫째 빈칸 = 기준인 알게 된 일 → 단순과거 learned. had learned·has learned로 시작하는 보기 지움 / 강조 `The manager _____` / 지움 `③ had learned — finished`, `④ had learned — had finished`, `⑤ has learned — have finished`<br>**3단계** 둘째 빈칸 = 더 먼저 끝낸 일 → had finished. finished만 쓴 ① 지움 → ② / 강조 `the team _____ the report already.`, `② learned — had finished` / 지움 `① learned — finished` | 첫째, 우리말을 보면 팀이 보고서를 끝낸 일이 먼저이고, 관리자가 그것을 알게 된 일이 나중이에요. 둘째, 첫째 빈칸은 기준이 되는 나중 일, 알게 된 일이라 단순과거 learned로 써요. 그래서 had learned나 has learned로 시작하는 3번, 4번, 5번을 지워요. 셋째, 둘째 빈칸은 그보다 더 먼저 끝낸 일이라 had finished로 써요. 그래서 finished만 쓴 1번도 지우면, 2번 learned와 had finished가 남아요. | 순서 → learned → had finished |
| 5. 선택지 확인 | 25초 | ① learned — finished  ✗  더 먼저 끝낸 일은 finished가 아니라 had finished로 써요<br>② learned — had finished  ✓  기준인 알게 된 일은 단순과거, 더 먼저 끝낸 일은 과거완료<br>③ had learned — finished  ✗  순서가 거꾸로: 알게 된 일이 끝낸 일보다 먼저가 돼요<br>④ had learned — had finished  ✗  기준인 알게 된 일은 had learned가 아니라 learned로 써요<br>⑤ has learned — have finished  ✗  현재완료는 지금이 기준이에요 (이 문장의 기준은 과거의 알게 된 때) | 정답은 2번 learned와 had finished예요. 1번은 finished만 써서, 끝낸 일이 알게 된 때보다 더 먼저라는 것을 시제로 나타내지 못해요. 4번처럼 알게 된 일까지 had learned로 쓰면 안 돼요. 기준이 되는 과거의 일은 단순과거로 써요. 3번은 순서를 거꾸로 써서, 알게 된 일이 끝낸 일보다 먼저가 돼요. | 정답 ② learned — had finished |

## 원본 해설

```
핵심 규칙: 과거의 한 시점(알게 된 때)을 기준으로 그보다 먼저 끝난 일은 had + 과거분사로 나타내고, 기준 시점의 일은 단순과거로 쓴다.
풀이 순서: ① 우리말에서 두 일의 순서를 가른다. ‘보고서를 끝낸 것’이 먼저, ‘안 것’이 나중이다. → ② 나중 일(주절)은 과거형으로, 그보다 먼저 일어난 일(that절)은 had + 과거분사로 쓴다. → ③ ‘과거형 — had + 과거분사’ 순서인 learned — had finished를 고른다.
문장별 판정:
정답 판단: 우리말에서 알게 된 일이 기준 시점이고 끝낸 일은 그보다 먼저 끝났으므로 learned — had finished가 알맞다.
선택지 분석:
① [오답] 둘째 빈칸 finished: 단순과거이어서 맞지 않는다. 그보다 먼저 끝난 that절의 일은 과거완료 had finished로 쓴다. 따라서 오답이다.
② [정답] 우리말에서 알게 된 일이 기준 시점이고 끝낸 일은 그보다 먼저 끝났으므로 learned — had finished가 알맞다. 모든 자리가 알맞으므로 정답이다.
③ [오답] 첫째 빈칸 had learned: 과거완료이어서 맞지 않는다. 기준 시점인 주절의 일은 단순과거 learned로 쓴다. 둘째 빈칸 finished: 단순과거이어서 맞지 않는다. 그보다 먼저 끝난 that절의 일은 과거완료 had finished로 쓴다. 따라서 오답이다.
④ [오답] 첫째 빈칸 had learned: 과거완료이어서 맞지 않는다. 기준 시점인 주절의 일은 단순과거 learned로 쓴다. 따라서 오답이다.
⑤ [오답] 첫째 빈칸 has learned: 현재완료이어서 맞지 않는다. 기준 시점인 주절의 일은 단순과거 learned로 쓴다. 둘째 빈칸 have finished: 현재완료이어서 맞지 않는다. 그보다 먼저 끝난 that절의 일은 과거완료 had finished로 쓴다. 따라서 오답이다.
```
