## 원본 해설

```
핵심 규칙: 일반동사의 과거 부정문과 의문문에서는 did/did not 뒤에 동사원형을 쓴다. 긍정문에서는 알맞은 과거형을 쓴다.
풀이 순서: ① 과거 부정문은 ‘didn't + 동사원형’이다. 주어와 관계없이 didn't를 쓴다. → ② 과거형 동사(wrote)를 원형(write)으로 되돌린다. → ③ didn't 뒤에 과거형을 그대로 둔 것, don't·wasn't를 쓴 것은 지운다. 정답은 ①.
문장별 판정:
정답 판단: 과거 일반동사 부정문은 did not(didn't) + 동사원형으로 만든다. 'I didn't write a letter.'는 didn't 뒤에 원형 'write'를 써서 정답은 ①이다.
선택지 분석:
① [정답] 과거 일반동사 부정문은 did not(didn't) + 동사원형으로 만든다. 'I didn't write a letter.'는 didn't 뒤에 원형 'write'를 써서 정답이다.
② [오답] 원문을 부정문으로 바꾸려면 did not(didn't)을 넣고 본동사를 원형 'write'로 바꿔야 한다. 'I write a letter.'는 이 조건을 충족하지 않아 오답이다.
③ [오답] 'write'는 일반동사이므로 be동사 부정형 was not/were not을 바로 붙이지 않는다. 과거 일반동사 부정문 'I didn't write a letter.'가 필요하다.
④ [오답] 원문은 과거이므로 현재 부정의 do/does not이 아니라 did not을 써야 한다. 'I didn't write a letter.'로 고쳐야 하므로 오답이다.
⑤ [오답] didn't가 이미 과거를 나타내므로 뒤에는 동사원형 'write'가 와야 한다. 'wrote'를 쓴 부분을 'write'로 고쳐야 하므로 오답이다.
```
