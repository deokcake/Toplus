| 3. 핵심 규칙 | 29초 | 핵심 규칙<br>목적어가 그 일을 직접 할 때 (‘목적어에게 …하게 하다’)<br>make / have / let + 목적어 + 동사원형<br>get + 목적어 + to부정사 (동사원형만 쓰면 ✗)<br>help + 목적어 + 동사원형 또는 to부정사 (‘…하도록 돕다’)<br>예) We got Tom to sing a song. | 5. 선택지 확인 | 28초 | ① The teacher got the class stay after school.  ✓  get + 목적어 뒤에는 to부정사 → to stay (틀린 문장)<br>② Mom made me clean the bathroom.  ✗  make + 목적어 + 동사원형 clean → 맞는 문장<br>③ He let his sister ride his new bike.  ✗  let + 목적어 + 동사원형 ride → 맞는 문장<br>④ The captain had the crew raise the flag.  ✗  have + 목적어 + 동사원형 raise → 맞는 문장<br>⑤ Sora helped her dad cook dinner.  ✗  help는 목적어 뒤에 동사원형도 가능 → 맞는 문장 | 정답은 1번이에요. got 뒤에 목적어 the class가 오고 동사원형 stay가 바로 와서 틀렸어요. 5번 helped her dad cook은 to가 없어서 틀렸다고 보기 쉽지만, help는 목적어 뒤에 동사원형과 to부정사를 둘 다 쓸 수 있어서 맞아요. 2번 made와 4번 had 뒤에도 to 없이 동사원형 clean과 raise를 써서 맞아요. | 정답 ① → to stay |
| 6. 정리 | 12초 | 정답 ① The teacher got the class stay after school.<br><br>목적어가 직접 할 때: make / have / let + 목적어 + 동사원형,  get + 목적어 + to부정사 | 정답은 1번이에요. 기억할 것, 목적어가 직접 할 때 make, have, let은 동사원형, get은 to부정사를 써요. | get + 목적어 + to부정사 |

## 원본 해설

```
핵심 규칙: make/have/let + 목적어 + 동사원형, get + 목적어 + to부정사 구조를 쓴다. help는 목적어 뒤에 동사원형과 to부정사를 모두 취할 수 있다. 목적어는 관사까지 포함한 명사구 전체로 본다.
풀이 순서: ① 문장마다 사역동사(make, have, let, help, get)와 목적어 뒤의 동사 형태를 짝짓는다. → ② make·have·let 뒤의 동사원형, help 뒤의 동사원형·to부정사는 모두 옳다. → ③ get만 to부정사가 필요한데 ①은 got + 목적어 뒤에 동사원형(stay)을 썼다. to부정사(to stay)로 고쳐야 한다.
문장별 판정:
정답 판단: ‘The teacher got the class stay after school.’은 get + 목적어 뒤에 동사원형 stay를 두었다. got the class to stay로 고쳐야 한다.
선택지 분석:
① [정답] get + 목적어 뒤에 동사원형 stay를 두었다. got the class to stay로 고쳐야 하므로 정답이다.
② [오답] ‘Mom made me clean the bathroom.’은 made + 목적어 + 동사원형 구조로 쓰여 올바르다. 잘못된 용법이 아니므로 오답이다.
③ [오답] ‘He let his sister ride his new bike.’은 let + 목적어 + 동사원형 구조로 쓰여 올바르다. 잘못된 용법이 아니므로 오답이다.
④ [오답] ‘The captain had the crew raise the flag.’은 had + 목적어 + 동사원형 구조로 쓰여 올바르다. 잘못된 용법이 아니므로 오답이다.
⑤ [오답] help는 목적어 뒤에 동사원형도 쓸 수 있으므로 ‘helped her dad cook’은 올바르다. 오답이다.
```
