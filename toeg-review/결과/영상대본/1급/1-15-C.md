| 3. 핵심 규칙 | 30초 | 핵심 규칙<br>현재완료(have + 과거분사) + 분명한 과거 시점(yesterday, ago) ✗<br>시간·조건의 부사절(when, after, if, unless) → 미래의 일도 현재시제<br>상태동사(contain, know, own 등) → 진행형 ✗ · have(먹다)는 동작이라 진행형 ○<br>had + 과거분사 = 과거의 어느 때보다 먼저 · will have + 과거분사 = 미래의 어느 때까지<br>예) If you need help, I will come. If you need help, I will come. 네가 도움이 필요하면 내가 갈게요. contain 같은 상태동사는 진행형으로 쓰지 않아요. 과거완료는 과거의 어느 때보다 앞선 일을, 미래완료는 미래의 어느 때까지 끝나거나 이어질 일을 나타내요. | 시간 표현에 맞는 시제 |
| 4. 풀이 순서 | 42초 | (장면 2의 판서를 그대로 두고 단계마다 강조·지움을 더한다)<br>**1단계** a) already + 현재완료 ✓ / e) discovered보다 먼저 → had left ✓ / f) By next June + 미래완료 ✓ / 강조 `already`, `had left`, `By next June`<br>**2단계** b) 조건의 if절 → will arrive ✗ → arrives / 강조 `If Tom` / 지움 `will arrive`<br>**3단계** c) have = 먹다(동작) → are having ✓ / d) contain = 담고 있다(상태) → is containing ✗ → contains / 틀린 문장 b), d) → 2개 / 강조 `are having`, `② 2개` / 지움 `is containing` | 첫째, 에이 문장은 already와 함께 이미 끝낸 일을 현재완료로, 이 문장 Jane discovered의 had left는 알게 된 것보다 먼저 가방을 두고 온 일을 과거완료로, 에프 문장은 다가오는 6월까지 이어질 일을 미래완료로 바르게 썼어요. 둘째, 비 문장은 조건을 나타내는 if절이라 미래의 일도 will arrive가 아니라 arrives로 써요. 셋째, 씨 문장의 have는 먹다라는 동작이라 are having이 옳지만, 디 문장의 contain은 담고 있다라는 상태라서 is containing이 아니라 contains를 써요. 따라서 틀린 문장은 비와 디, 두 개예요. | 완료 → 부사절 → 진행형 |

## 원본 해설

```
핵심 규칙: 끝난 과거·현재까지의 경험과 상태·과거 사건의 선후·미래 기준의 완료를 구별한다. 미래의 단순 조건·시간절에는 현재형을 쓰며, 이 문항의 정적인 상태 동사는 진행형을 쓰지 않는다.
풀이 순서: ① 밑줄 친 동사마다 함께 쓰인 시간 표현과 접속사를 짝짓는다. → ② if절의 will arrive(b), 상태동사 contain의 진행형(d)이 틀렸다. are having(먹다)과 by next June이 있는 will have worked는 옳다. → ③ 틀린 문장을 세면 2개이다.
문장별 판정:
a) 옳음: has finished는 이미 보고서를 마친 현재완료이다.
b) 틀림: 단순한 미래 조건의 if절에는 현재형을 쓴다. will arrive → arrives.
c) 옳음: are having은 식사하는 동작의 진행이다.
d) 틀림: contain은 ‘담고 있다’는 상태동사라 진행형으로 쓰지 않는다. is containing → contains.
e) 옳음: had left는 discovered보다 먼저 가방을 두고 온 일을 나타낸다.
f) 옳음: will have worked는 다음 6월까지의 근무 기간을 나타낸다.
정답 판단: 어법상 틀린 문장은 b, d의 2개이다.
선택지 분석:
① [오답] 어법상 틀린 문장은 b, d의 2개이다. 이 보기의 1개는 실제 개수와 일치하지 않는다.
② [정답] 어법상 틀린 문장은 b, d의 2개이다. 이 보기의 2개는 실제 개수와 일치한다.
③ [오답] 어법상 틀린 문장은 b, d의 2개이다. 이 보기의 3개는 실제 개수와 일치하지 않는다.
④ [오답] 어법상 틀린 문장은 b, d의 2개이다. 이 보기의 4개는 실제 개수와 일치하지 않는다.
⑤ [오답] 어법상 틀린 문장은 b, d의 2개이다. 이 보기의 5개는 실제 개수와 일치하지 않는다.
```
