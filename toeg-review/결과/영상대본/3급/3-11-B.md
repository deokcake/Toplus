## 원본 해설

```
핵심 규칙: 일반동사의 과거 부정문은 did not(didn't) + 동사원형으로 만든다. don't/doesn't는 현재, was(n't)는 be동사 문장에 쓴다.
풀이 순서: ① 과거 부정문은 ‘didn't + 동사원형’이다. 주어와 관계없이 didn't를 쓴다. → ② 과거형 동사(cleaned)를 원형(clean)으로 되돌린다. → ③ didn't 뒤에 과거형을 그대로 둔 것, don't·wasn't를 쓴 것은 지운다. 정답은 ③.
문장별 판정:
정답 판단: didn't + 동사원형으로 바르게 바꿨으므로 정답은 ③이다.
선택지 분석:
① [오답] didn't 뒤에는 동사원형(clean)을 써야 하므로 오답이다.
② [오답] doesn't는 현재 부정이라 과거 문장과 시제가 맞지 않으므로 오답이다.
③ [정답] didn't + 동사원형으로 바르게 바꿨으므로 정답이다.
④ [오답] 일반동사 문장에는 wasn't를 쓰지 않으므로 오답이다.
⑤ [오답] not만 넣어서는 부정문이 되지 않으므로 오답이다.
```
