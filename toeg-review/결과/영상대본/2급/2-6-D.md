## 원본 해설

```
핵심 규칙: 4형식을 3형식으로 바꿀 때는 ‘주어 + 동사 + 직접목적어(사물) + 전치사 + 간접목적어(사람)’ 순서로 쓴다. give·send·show·teach는 to, buy·make는 for를 쓴다.
풀이 순서: ① 3형식은 ‘동사 + 사물 + 전치사 + 사람’이다. 사물(the map)이 동사 바로 뒤로 와야 한다. → ② 동사(show)에 맞는 전치사는 to다. → ③ 어순과 전치사가 모두 맞는 ②를 고른다.
문장별 판정:
정답 판단: 사물 + to + 사람 순서로 바르게 바꿨다. 정답은 ②이다.
선택지 분석:
① [오답] 전치사 + 사람을 사물 앞에 두어 어순이 틀렸다. 오답이다.
② [정답] 사물 + to + 사람 순서로 바르게 바꿨다. 정답이다.
③ [오답] ‘우리를 지도로 안내했다’는 다른 뜻이 되었다. 오답이다.
④ [오답] show는 보는 사람 앞에 to를 쓴다. 오답이다.
⑤ [오답] 사람 앞에 전치사가 없어 3형식이 되지 않는다. 오답이다.
```
