# 2차 감수(2026-10-02~, Fable 5.1) 기준과 작업 방식

## 할 일 (문항 묶음 = 원문항 + B~F 변형 + Claude 수정 예시)
1. 모든 문항을 직접 다시 푼다(정답·정답 유일성). 변형(V), 수정 예시(F), 사람이 고친 상태(E) 모두.
2. 변형 판정(v)을 다시 본다. 바뀌면 RV(..., v=...)로 기록하고, 적합→수정이면 fx/에 수정 예시(F)를 새로 만든다.
3. 수정 예시에 결함이 있으면 fx/를 고치고 RV(..., fx=True, why=...)로 기록한다.
4. 원문항 해설을 X(...)로 쓴다: 핵심 규칙 r, 보기별 해설 n(5개), 필요하면 정답 판단 k.
5. 풀이 순서 틀 st와 문항별 칸(R, B~F)을 쓴다. ‘풀이○’ 표시된 유형만 칸이 필요하다(수정 예시가 있으면 그 예시 기준, 없으면 변형 기준).

## 감수 기준 (rubric + 사용자가 메모로 준 기준)
- C1 정답 유일성·정답 오류(치명). 영어 원어민 수용성까지 본다.
- 발문은 (고친) 원문항과 같아야 한다. 조건은 발문에 명시.
- 밑줄 범위·빈칸 형식·<보기> 표시·기호가 원문항과 같아야 한다(사용자: 밑줄 범위가 다르면 부적합/수정).
- 제시문·문장 길이는 원문항 수준(±30%).
- 보기 수준은 원문항 수준: 없는 형태(worseest)·뻔한 오답·형식만으로 지워지는 오답 금지.
- 단어 배열 문항에 필요 없는 단어 금지(원문항이 그렇지 않은 한).
- 현재/진행 둘 다 되는 애매한 오답 금지 → 시제·시간 표현이 어긋난 오답으로.
- 두 문장을 화살표 없이 따로 제시(원문항이 그런 경우).
- 원문항이 보기마다 3문장 조합이면 변형도 그렇게.
- 원문항·다른 유형과 같은 문장·같은 정답 조합 금지(노출).

## 풀이 순서 쓰는 법
- 일반론(‘발문을 확인한다’, ‘각 선택지를 판정한다’) 금지. 이 문항에서 어디를 보고(단서), 어떤 규칙을 적용하고, 어떤 함정을 지우는지 쓴다.
- 2~4단계, ‘① … → ② … → ③ …’. 정답 보기는 {a}, 정답 번호는 {n}.
- 문항마다 다른 단서(시간 부사, 선행사, 동사 등)는 {0}, {1} 칸으로.
