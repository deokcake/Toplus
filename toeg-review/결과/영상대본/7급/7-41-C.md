## 원본 해설

```
핵심 규칙: 지시 대상의 거리·복수와 are에 맞는 대명사이다.
풀이 순서: ① 빈칸 뒤가 are이므로 한 개를 가리키는 This, That, It을 지운다. → ② 우리말이 ‘이것들’이므로 가까이 있는 여러 개를 가리킨다. → ③ 정답은 These.
문장별 판정:
정답 판단: 정답은 ④입니다. 가까이 있는 여러 대상을 가리키며 be동사가 are입니다. ‘These’는 가까운 복수 대상을 가리킵니다. 이 문맥에는 These가 맞습니다.
선택지 분석:
① [오답] 가까이 있는 여러 대상을 가리키며 be동사가 are입니다. ‘This’는 가까운 단수 대상을 가리킵니다. 이 문맥에는 These가 맞습니다. 바르게 고치면: These
② [오답] 가까이 있는 여러 대상을 가리키며 be동사가 are입니다. ‘It’은 주격·목적격 형태로 ‘그것은/그것을’의 뜻입니다. 대상의 거리와 수를 함께 나타내는 These가 필요합니다. 바르게 고치면: These
③ [오답] 가까이 있는 여러 대상을 가리키며 be동사가 are입니다. ‘Those’는 먼 복수 대상을 가리킵니다. 이 문맥에는 These가 맞습니다. 바르게 고치면: These
④ [정답] 가까이 있는 여러 대상을 가리키며 be동사가 are입니다. ‘These’는 가까운 복수 대상을 가리킵니다. 이 문맥에는 These가 맞습니다.
⑤ [오답] 가까이 있는 여러 대상을 가리키며 be동사가 are입니다. ‘That’은 먼 단수 대상을 가리킵니다. 이 문맥에는 These가 맞습니다. 바르게 고치면: These
```
